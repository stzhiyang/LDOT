# Box关联优化 - 最终完整方案

## 问题回顾

经过多轮调试,我们发现关联问题的演变过程:
1. **初期**: 关联成功率低,大量NaN错误
2. **中期**: 修复NaN后,发现关联随时间退化(初始好,后来差)
3. **根因**: 卡尔曼滤波参数过于保守,导致对加速/转弯物体预测发散,产生巨大的代价值(>200)

## 最终修复方案 (三管齐下)

### 1. 代价计算简化 (已完成)
- **策略**: 放弃马氏距离,改用**纯欧式距离**
- **优势**: 彻底消除协方差求逆导致的NaN风险,计算更稳定
- **代码**: 移除了尺寸和标准差代价,仅保留位置欧式距离

### 2. 门限调整 (已完成)
- **数值**: **25.0** (约5米)
- **目的**: 适应卡尔曼滤波在动态场景下的预测误差

### 3. 卡尔曼滤波参数优化 (本次核心)

针对CV模型(常速模型)进行了关键调整,使其更"灵活":

| 参数 | 原值 | 新值 | 作用 |
|------|------|------|------|
| **过程噪声 sigma** | 1.0 | **3.0** | Q矩阵增大9倍! 允许物体有更大的加速度变化 |
| **测量噪声 R** | 0.1 | **0.3** | 更真实地反映激光雷达误差,防止过拟合 |
| **初始位置 P** | 0.1 | **0.5** | 初始位置不确定性增大 |
| **初始速度 P** | 1.0 | **2.0** | 初始速度不确定性增大 |
