# 动态障碍物检测器 - 数学公式与调参详解

本文档详细介绍检测器、跟踪器和动静态分类器中使用的数学公式，并在每个公式后提供详细的调参指南。

---

## 1. 检测器 (lidarDetectionCB)

### 1.1 DBSCAN 聚类算法

#### 公式

```
ε_adaptive = ε_base + d × scale
```

#### 参数说明

| 变量 | 含义 | 配置参数 | 默认值 |
|------|------|----------|--------|
| `ε_base` | 基础邻域半径 | `lidar_DBSCAN_epsilon` | 0.2m |
| `d` | 点到传感器的距离 | - | 实时计算 |
| `scale` | 距离缩放因子 | `lidar_DBSCAN_distance_scale` | 0.02 |
| `minPts` | 最小点数阈值 | `lidar_DBSCAN_min_points` | 10 |

#### 原理

激光雷达点云密度随距离增加而降低（角分辨率固定），因此需要自适应调整邻域半径：
- 近距离（2m）：点云密集，ε = 0.2 + 2×0.02 = 0.24m
- 远距离（10m）：点云稀疏，ε = 0.2 + 10×0.02 = 0.4m

#### 调参指南

| 问题现象 | 原因分析 | 调参方向 |
|----------|----------|----------|
| 近距离物体被过度分割 | ε_base 太小 | 增大 `lidar_DBSCAN_epsilon` 到 0.25-0.3 |
| 近距离多个物体被合并 | ε_base 太大 | 减小 `lidar_DBSCAN_epsilon` 到 0.1-0.15 |
| 远距离物体检测不到 | 远距离ε不够大 | 增大 `lidar_DBSCAN_distance_scale` 到 0.03-0.05 |
| 远距离噪声被误检 | 远距离ε太大 | 减小 `lidar_DBSCAN_distance_scale` 到 0.01 |
| 小物体检测不到 | minPts 太大 | 减小 `lidar_DBSCAN_min_points` 到 5-8 |
| 噪声点被误检为物体 | minPts 太小 | 增大 `lidar_DBSCAN_min_points` 到 15-20 |

#### 典型配置

```yaml
# 室内场景（距离近、物体小）
lidar_DBSCAN_epsilon: 0.15
lidar_DBSCAN_distance_scale: 0.01
lidar_DBSCAN_min_points: 8

# 室外场景（距离远、物体大）
lidar_DBSCAN_epsilon: 0.25
lidar_DBSCAN_distance_scale: 0.03
lidar_DBSCAN_min_points: 15

# 密集人群场景
lidar_DBSCAN_epsilon: 0.12
lidar_DBSCAN_distance_scale: 0.015
lidar_DBSCAN_min_points: 5
```

### 1.2 静态体素滤波器

#### 公式

```
is_static = (hit_count > hit_threshold)
static_ratio = static_points / total_points
is_static_cluster = (static_ratio > static_cluster_filter_ratio)
```

#### 参数说明

| 变量 | 含义 | 配置参数 | 默认值 |
|------|------|----------|--------|
| `hit_count` | 体素被观测次数 | - | 累积计算 |
| `hit_threshold` | 静态判定阈值 | `static_filter_hit_threshold` | 10 |
| `static_ratio` | 聚类中静态点占比 | - | 实时计算 |
| `static_cluster_filter_ratio` | 静态聚类阈值 | `static_cluster_filter_ratio` | 0.6 |

#### 原理

- 静态物体（墙壁、地面）会在同一位置被反复观测，hit_count 累积增加
- 动态物体位置变化，hit_count 不会累积
- 当聚类中超过60%的点是静态点时，认为整个聚类是静态的

#### 调参指南

| 问题现象 | 原因分析 | 调参方向 |
|----------|----------|----------|
| 静态物体被误判为动态 | hit_threshold 太高 | 减小到 5-8 |
| 动态物体被误判为静态 | hit_threshold 太低 | 增大到 15-20 |
| 静态背景过滤不干净 | static_cluster_filter_ratio 太高 | 减小到 0.4-0.5 |
| 动态物体被误过滤 | static_cluster_filter_ratio 太低 | 增大到 0.7-0.8 |
| 短暂停留的物体被误判 | 累积太快 | 增大 hit_threshold |

#### 典型配置

```yaml
# 静态环境多（办公室、仓库）
static_filter_hit_threshold: 8
static_cluster_filter_ratio: 0.5

# 动态环境多（街道、广场）
static_filter_hit_threshold: 15
static_cluster_filter_ratio: 0.7

# 混合环境
static_filter_hit_threshold: 10
static_cluster_filter_ratio: 0.6
```

## 2. 跟踪器 (trackingCB)

### 2.1 卡尔曼滤波器 - 过程噪声 Q

#### 公式

**CV模型（恒定速度）：**
```
Q_block(2×2) = [dt⁴/4  dt³/2] × σ_acc²
               [dt³/2  dt²  ]
```

**CA模型（恒定加速度）：**
```
Q_block(3×3) = [dt⁵/20  dt⁴/8   dt³/6]
               [dt⁴/8   dt³/3   dt²/2] × σ_jerk²
               [dt³/6   dt²/2   dt   ]
```

#### 参数说明

| 参数 | 含义 | 配置路径 | 默认值 |
|------|------|----------|--------|
| `σ_acc` | 加速度噪声标准差 | `kalman_filter/cv_model/acc_sigma` | 3.0 m/s² |
| `σ_jerk` | 加加速度噪声标准差 | `kalman_filter/ca_model/*/jerk_sigma` | 3.0 m/s³ |
| `dt` | 时间步长 | `time_step` | 0.1s |

#### 原理

- Q 描述了模型的不确定性（目标可能的加速度/加加速度变化）
- σ 越大 → Q 越大 → 滤波器更信任测量，响应快但噪声大
- σ 越小 → Q 越小 → 滤波器更信任模型，平滑但响应慢

#### 调参指南

| 问题现象 | 原因分析 | 调参方向 |
|----------|----------|----------|
| 跟踪滞后，跟不上快速运动 | σ 太小，Q 太小 | 增大 `acc_sigma`/`jerk_sigma` 到 5-10 |
| 跟踪抖动，轨迹不平滑 | σ 太大，Q 太大 | 减小 `acc_sigma`/`jerk_sigma` 到 1-2 |
| 加速时轨迹断裂 | Q 太小，预测误差大 | 增大 σ |
| 匀速运动时轨迹抖动 | Q 太大 | 减小 σ |

#### 调参公式

```
σ_acc ≈ 预期最大加速度 × 0.5 ~ 1.0
σ_jerk ≈ 预期最大加加速度 × 0.5 ~ 1.0

例如：
- 行人（a_max ≈ 3 m/s²）：σ_acc = 1.5 ~ 3.0
- 车辆（a_max ≈ 5 m/s²）：σ_acc = 2.5 ~ 5.0
- 无人机（a_max ≈ 10 m/s²）：σ_acc = 5.0 ~ 10.0
```

#### 典型配置

```yaml
# 低机动目标（行人）
kalman_filter:
  cv_model:
    acc_sigma: 2.0
  ca_model:
    human:
      jerk_sigma: 2.0

# 高机动目标（无人机）
kalman_filter:
  ca_model:
    uav:
      jerk_sigma: 8.0

# 车辆
kalman_filter:
  ctra_model:
    process_noise: [0.1, 0.1, 0.01, 2.0, 15.0, 1.0, 15.0]
```

### 2.2 卡尔曼滤波器 - 测量噪声 R

#### 公式

```
R = diag(σ_x², σ_y², σ_z²)
```

#### 参数说明

| 参数 | 含义 | 配置路径 | 默认值 |
|------|------|----------|--------|
| `meas_noise` | 测量噪声方差 | `kalman_filter/*/meas_noise` | [0.1, 0.1, 0.1] |

#### 原理

- R 描述了测量的不确定性（LiDAR检测的位置误差）
- σ² = 0.1 → 标准差 ≈ 0.32m，表示测量误差在 ±0.32m 范围内
- R 越大 → 滤波器越不信任测量，更依赖预测
- R 越小 → 滤波器越信任测量，跟踪更紧

#### 调参指南

| 问题现象 | 原因分析 | 调参方向 |
|----------|----------|----------|
| 跟踪位置与检测偏差大 | R 太大 | 减小 `meas_noise` 到 [0.05, 0.05, 0.05] |
| 跟踪受检测噪声影响大 | R 太小 | 增大 `meas_noise` 到 [0.2, 0.2, 0.2] |
| 远距离跟踪不稳定 | 远距离测量噪声大 | 可考虑距离自适应R |

#### 调参公式

```
σ² ≈ (预期测量误差)²

例如：
- 高精度LiDAR（误差 ±0.1m）：meas_noise = [0.01, 0.01, 0.01]
- 普通LiDAR（误差 ±0.3m）：meas_noise = [0.1, 0.1, 0.1]
- 低精度/远距离（误差 ±0.5m）：meas_noise = [0.25, 0.25, 0.25]
```

### 2.3 协方差上限

#### 公式

```
P(i,i) = min(P(i,i), max_cov)
```

#### 参数说明

| 参数 | 含义 | 配置路径 | 默认值 |
|------|------|----------|--------|
| `max_pos_cov` | 位置协方差上限 | `kalman_filter/max_pos_cov` | 9.0 m² |
| `max_vel_cov` | 速度协方差上限 | `kalman_filter/max_vel_cov` | 16.0 (m/s)² |
| `max_acc_cov` | 加速度协方差上限 | `kalman_filter/max_acc_cov` | 100.0 (m/s²)² |

#### 原理

- 当目标丢失时，P 会持续增长（每次 predict 都加 Q）
- P 过大会导致马氏距离过小，容易产生错误关联
- 设置上限防止 P 无限增长

#### 调参指南

| 问题现象 | 原因分析 | 调参方向 |
|----------|----------|----------|
| 静态物体抢走动态物体的关联 | max_pos_cov 太大 | 减小到 1.0-2.0 |
| 高机动目标关联失败 | max_pos_cov 太小 | 增大到 4.0-9.0 |
| 快速目标轨迹断裂 | max_vel_cov 太小 | 增大到 v_max² |

#### 调参公式

```
max_pos_cov = (可接受的最大预测误差)²
max_vel_cov = v_max²
max_acc_cov = a_max²

例如（v_max=3m/s, a_max=5m/s²）：
max_pos_cov = 1.5  # 容忍1.2m预测误差
max_vel_cov = 9.0  # 3²
max_acc_cov = 25.0 # 5²
```

#### 典型配置

```yaml
# 低速场景（v_max=2m/s）
kalman_filter:
  max_pos_cov: 1.0
  max_vel_cov: 4.0
  max_acc_cov: 16.0

# 高速场景（v_max=5m/s）
kalman_filter:
  max_pos_cov: 2.0
  max_vel_cov: 25.0
  max_acc_cov: 100.0
```

### 2.4 马氏距离与关联门限

#### 公式

```
D_mahal² = Δpᵀ × P_pos⁻¹ × Δp
gate_threshold = χ²(3, confidence)
```

#### 参数说明

| 参数 | 含义 | 配置参数 | 默认值 |
|------|------|----------|--------|
| `confidence` | 关联置信度 | `association_gate_confidence` | 0.99 |

| 置信度 | 门限值 | 含义 |
|--------|--------|------|
| 0.90 | 6.25 | 宽松，容易关联 |
| 0.95 | 7.81 | 中等 |
| 0.99 | 11.34 | 严格，不易误关联 |
| 0.999 | 16.27 | 非常严格 |

#### 原理

- 马氏距离考虑了预测的不确定性（P矩阵）
- P 大 → 马氏距离小 → 更容易通过门限
- 门限基于卡方分布，置信度越高门限越大

#### 调参指南

| 问题现象 | 原因分析 | 调参方向 |
|----------|----------|----------|
| 不同物体被错误关联 | 门限太宽松 | 增大 confidence 到 0.99-0.999 |
| 同一物体关联失败 | 门限太严格 | 减小 confidence 到 0.90-0.95 |
| 密集场景关联混乱 | 门限太宽松 | 增大 confidence |

### 2.5 关联代价权重

#### 公式

```
cost = w_pos × D_mahal² + w_iou × (1 - IoU_3D)
```

#### 参数说明

| 参数 | 含义 | 配置参数 | 默认值 |
|------|------|----------|--------|
| `w_pos` | 位置代价权重 | `association_pos_cost_weight` | 0.8 |
| `w_iou` | IoU代价权重 | `association_iou_cost_weight` | 1.0 |

#### 调参指南

| 问题现象 | 原因分析 | 调参方向 |
|----------|----------|----------|
| 位置近但尺寸差异大的物体被关联 | w_iou 太小 | 增大到 1.5-2.0 |
| 尺寸相似但位置远的物体被关联 | w_pos 太小 | 增大到 1.0-1.5 |
| 尺寸变化大的物体关联失败 | w_iou 太大 | 减小到 0.3-0.5 |

## 3. 分类器 (classificationCB)

### 3.1 点云速度投票

#### 公式

```
V_point = (p_curr - p_nearest) / (dt × frame_gap)
vote_ratio = votes / num_points
is_dynamic = (vote_ratio ≥ vote_threshold) && (|V_kf| ≥ vel_threshold)
```

#### 参数说明

| 参数 | 含义 | 配置参数 | 默认值 |
|------|------|----------|--------|
| `frame_gap` | 帧间隔 | `frame_skip` | 3 |
| `vel_threshold` | 速度阈值 | `dynamic_velocity_threshold` | 0.1 m/s |
| `vote_threshold` | 投票阈值 | `dynamic_voting_threshold` | 0.7 |

#### 原理

- 比较当前帧和历史帧的点云位置变化
- 如果超过70%的点速度超过阈值，认为是动态候选
- 同时要求卡尔曼滤波器估计的速度也超过阈值

#### 调参指南

| 问题现象 | 原因分析 | 调参方向 |
|----------|----------|----------|
| 静态物体被误判为动态 | vel_threshold 太低 | 增大到 0.15-0.3 |
| 慢速物体检测不到 | vel_threshold 太高 | 减小到 0.05-0.08 |
| 部分运动物体误判 | vote_threshold 太高 | 减小到 0.5-0.6 |
| 噪声导致误判 | vote_threshold 太低 | 增大到 0.8-0.9 |
| 快速运动检测滞后 | frame_skip 太大 | 减小到 1-2 |
| 慢速运动检测不稳定 | frame_skip 太小 | 增大到 4-5 |

#### 调参公式

```
vel_threshold ≈ 最小关心速度 × 0.5
frame_skip ≈ 1 / (vel_threshold × dt)  # 确保位移可检测

例如：
- 关心 > 0.3m/s 的运动：vel_threshold = 0.15, frame_skip = 3
- 关心 > 0.1m/s 的运动：vel_threshold = 0.05, frame_skip = 5
```

#### 典型配置

```yaml
# 检测慢速目标（行人）
frame_skip: 5
dynamic_velocity_threshold: 0.08
dynamic_voting_threshold: 0.6

# 检测快速目标（车辆）
frame_skip: 2
dynamic_velocity_threshold: 0.3
dynamic_voting_threshold: 0.7

# 高噪声环境
frame_skip: 3
dynamic_velocity_threshold: 0.15
dynamic_voting_threshold: 0.85
```

### 3.2 动态一致性检查

#### 公式

```
dyna_consist_count = Σ (is_dynamic[j] || is_dynamic_candidate[j])
is_dynamic = (dyna_consist_count == dynamic_consistency_threshold)
```

#### 参数说明

| 参数 | 含义 | 配置参数 | 默认值 |
|------|------|----------|--------|
| `dynamic_consistency_threshold` | 一致性帧数 | `dynamic_consistency_threshold` | 3 |

#### 调参指南

| 问题现象 | 原因分析 | 调参方向 |
|----------|----------|----------|
| 动态物体检测延迟大 | 阈值太高 | 减小到 2 |
| 瞬时噪声导致误判 | 阈值太低 | 增大到 4-5 |

### 3.3 滞后机制

#### 公式

```
effective_threshold = vel_threshold × hysteresis_lower  (动态→静态)
effective_threshold = vel_threshold                      (静态→动态)
```

#### 参数说明

| 参数 | 含义 | 配置参数 | 默认值 |
|------|------|----------|--------|
| `hysteresis_lower` | 滞后系数 | `hysteresis_lower` | 0.7 |

#### 原理

- 已经是动态的物体，用更低的阈值判断是否变静态
- 防止物体在动态/静态之间频繁切换

#### 调参指南

| 问题现象 | 原因分析 | 调参方向 |
|----------|----------|----------|
| 动态物体频繁切换状态 | hysteresis_lower 太高 | 减小到 0.5-0.6 |
| 停止的物体迟迟不变静态 | hysteresis_lower 太低 | 增大到 0.8-0.9 |

---

### 3.4 动态转静态回退

#### 公式

```
implied_vel = |pos[0] - pos[k]| / (k × dt)
dir_consistency = (motion1 · motion2) / (|motion1| × |motion2|)
is_stationary = (implied_vel < threshold) || (dir_consistency < dir_thresh && implied_vel < 3×threshold)
```

#### 参数说明

| 参数 | 含义 | 配置参数 | 默认值 |
|------|------|----------|--------|
| `static_vel_threshold` | 静止速度阈值 | `static_fallback_vel_threshold` | 0.1 m/s |
| `dir_threshold` | 方向一致性阈值 | `motion_dir_consistency_threshold` | 0.867 |
| `fallback_frames` | 回退帧数 | `static_fallback_frames` | 5 |

#### 方向一致性参考

| 余弦值 | 夹角 | 含义 |
|--------|------|------|
| 1.0 | 0° | 完全一致（真实运动） |
| 0.867 | 30° | 较一致 |
| 0.5 | 60° | 中等（可能是抖动） |
| 0 | 90° | 垂直（抖动） |

#### 调参指南

| 问题现象 | 原因分析 | 调参方向 |
|----------|----------|----------|
| 停止的物体不回退 | static_vel_threshold 太低 | 增大到 0.15-0.2 |
| 慢速物体被误回退 | static_vel_threshold 太高 | 减小到 0.05-0.08 |
| 抖动被误判为运动 | dir_threshold 太低 | 增大到 0.9 |
| 真实运动被误判为抖动 | dir_threshold 太高 | 减小到 0.7 |
| 回退太快 | fallback_frames 太小 | 增大到 8-10 |
| 回退太慢 | fallback_frames 太大 | 减小到 3-4 |

#### 典型配置

```yaml
# 高精度场景（抖动小）
static_fallback_vel_threshold: 0.05
motion_dir_consistency_threshold: 0.95
static_fallback_frames: 3

# 低精度场景（抖动大）
static_fallback_vel_threshold: 0.15
motion_dir_consistency_threshold: 0.7
static_fallback_frames: 8
```
