# 点云预处理数学公式

## 1. 算法流程

点云预处理旨在**平衡计算效率与几何特征保真性**。原始点云包含大量冗余和噪声点，直接处理会导致计算负担过重。预处理通过两步滤波实现高效降采样：

1. **范围带通滤波**：保留包含潜在动态物体的有效范围（垂直+水平）
2. **体素下采样**：在确保几何特征可靠的前提下降低点云密度

完整流程可表示为：

$$
\boxed{\mathcal{P}_{\text{proc}} = \mathcal{V}_\ell(\mathcal{R}(\mathcal{H}(\mathcal{P}_{\text{raw}})))}
$$

其中 $\mathcal{H}$ 为高度过滤，$\mathcal{R}$ 为范围过滤，$\mathcal{V}_\ell$ 为体素下采样。

## 2. 核心公式

### 2.1 点云定义与符号约定

**点云定义**：设世界坐标系下的原始点云为有限点集：

$$
\mathcal{P}_{\text{raw}} = \{\mathbf{p}_i \in \mathbb{R}^3 : i = 1, 2, \ldots, N\}
$$

其中 $N$ 为点云总数，$\mathbf{p}_i = [x_i, y_i, z_i]^T$ 为第 $i$ 个点的三维坐标。

**符号约定**：
- $\mathcal{P}$：点云集合
- $\mathbf{p} = [x, y, z]^T$：三维点坐标
- $\mathcal{H}, \mathcal{R}, \mathcal{V}_\ell$：过滤算子
- $h_{\min}, h_{\max}$：高度阈值
- $r_x, r_y$：水平范围参数
- $\ell$：体素边长

### 2.2 高度过滤（垂直带通）

**目的**：去除地面和天花板点，保留包含潜在动态物体的垂直范围。

**数学定义**：给定高度阈值 $h_{\min}, h_{\max} \in \mathbb{R}$，高度过滤算子为：

$$
\mathcal{H}(\mathcal{P}) = \{\mathbf{p} \in \mathcal{P} : h_{\min} \leq p_z \leq h_{\max}\}
$$

**变量说明**：

| 变量 | 含义 | 典型值 |
|------|------|--------|
| $p_z$ | 点的高度坐标（$z$ 分量） | - |
| $h_{\min}$ | 地面高度阈值 | -0.5 m |
| $h_{\max}$ | 天花板高度阈值 | 3.0 m |

**几何意义**：定义一个水平带状区域 $[h_{\min}, h_{\max}]$，只保留该区域内的点。

### 2.3 范围过滤（水平带通）

**目的**：保留传感器周围的有效检测范围，去除远距离噪声点。

**数学定义**：给定传感器位置 $\mathbf{s} = [s_x, s_y, s_z]^T$ 和范围参数 $r_x, r_y \in \mathbb{R}^+$，范围过滤算子为：

$$
\mathcal{R}(\mathcal{P}) = \{\mathbf{p} \in \mathcal{P} : |p_x - s_x| \leq r_x \land |p_y - s_y| \leq r_y\}
$$

这定义了一个以传感器为中心的**矩形检测区域**。

**双范围策略**：

为了静态地图更新的鲁棒性，系统采用两个范围：

1. **扩展范围**（用于静态地图更新）：
$$
\mathcal{R}_{\text{ext}}(\mathcal{P}) = \{\mathbf{p} \in \mathcal{P} : |p_x - s_x| \leq r_x + \delta \land |p_y - s_y| \leq r_y + \delta\}
$$

2. **检测范围**（用于聚类和跟踪）：
$$
\mathcal{R}_{\text{det}}(\mathcal{P}) = \{\mathbf{p} \in \mathcal{P} : |p_x - s_x| \leq r_x \land |p_y - s_y| \leq r_y\}
$$

**变量说明**：

| 变量 | 含义 | 典型值 |
|------|------|--------|
| $\mathbf{s}$ | 传感器位置（世界坐标系） | 动态更新 |
| $r_x, r_y$ | 检测范围（X/Y方向） | 10 m |
| $\delta$ | 缓冲距离 | 2 m |

**包含关系**：
$$
\mathcal{R}_{\text{det}}(\mathcal{P}) \subseteq \mathcal{R}_{\text{ext}}(\mathcal{P}) \subseteq \mathcal{P}
$$

**示例**：假设传感器位于 $(0, 0, 0)$，检测范围 $r_x = r_y = 10\text{m}$，缓冲距离 $\delta = 2\text{m}$，则：
- 检测范围：$[-10, 10] \times [-10, 10]$
- 扩展范围：$[-12, 12] \times [-12, 12]$

### 2.4 体素下采样

**目的**：在确保几何特征可靠的前提下，通过空间量化降低点云密度。

**体素网格定义**：给定体素边长 $\ell \in \mathbb{R}^+$，将三维空间划分为规则网格：

$$
\mathcal{G}_\ell = \left\{\mathcal{V}_{ijk} : i, j, k \in \mathbb{Z}\right\}
$$

其中每个体素 $\mathcal{V}_{ijk}$ 为立方体：

$$
\mathcal{V}_{ijk} = [i\ell, (i+1)\ell) \times [j\ell, (j+1)\ell) \times [k\ell, (k+1)\ell)
$$

**体素索引映射**：点 $\mathbf{p}$ 所属的体素索引为：

$$
\nu(\mathbf{p}) = \left\lfloor \frac{\mathbf{p}}{\ell} \right\rfloor = \left[\left\lfloor \frac{x}{\ell} \right\rfloor, \left\lfloor \frac{y}{\ell} \right\rfloor, \left\lfloor \frac{z}{\ell} \right\rfloor\right]^T
$$

其中 $\lfloor \cdot \rfloor$ 为向下取整函数。

**体素下采样算子**：将每个非空体素内的所有点替换为其质心：

$$
\mathcal{V}_\ell(\mathcal{P}) = \left\{\bar{\mathbf{p}}_{ijk} : \mathcal{P}_{ijk} \neq \emptyset\right\}
$$

其中：
- $\mathcal{P}_{ijk} = \{\mathbf{p} \in \mathcal{P} : \nu(\mathbf{p}) = (i,j,k)\}$ 为体素内的点集
- $\bar{\mathbf{p}}_{ijk}$ 为体素内点的质心：

$$
\bar{\mathbf{p}}_{ijk} = \frac{1}{|\mathcal{P}_{ijk}|} \sum_{\mathbf{p} \in \mathcal{P}_{ijk}} \mathbf{p}
$$

**变量说明**：

| 变量 | 含义 | 典型值 |
|------|------|--------|
| $\ell$ | 体素边长 | 0.1 m |
| $\mathcal{V}_{ijk}$ | 索引为 $(i,j,k)$ 的体素 | - |
| $\mathcal{P}_{ijk}$ | 体素内的点集 | - |
| $\bar{\mathbf{p}}_{ijk}$ | 体素内点的质心 | - |

**几何意义**：
- **均匀性**：确保点云在空间上均匀分布
- **代表性**：质心代表体素内所有点的平均位置
- **可控性**：通过调整 $\ell$ 控制降采样程度

**误差界**：体素内任意点到质心的最大距离为：

$$
d_{\max} = \frac{\sqrt{3}}{2} \ell
$$

这是体素对角线长度的一半。对于 $\ell = 0.1\text{m}$，$d_{\max} \approx 0.087\text{m}$。

### 2.5 性能分析

**时间复杂度**：

$$
T_{\text{total}} = \mathcal{O}(N) + \mathcal{O}(M) + \mathcal{O}(K) = \mathcal{O}(N)
$$

其中：
- $N = |\mathcal{P}_{\text{raw}}|$：原始点云大小
- $M = |\mathcal{H}(\mathcal{P}_{\text{raw}})|$：高度过滤后点云大小
- $K = |\mathcal{V}_\ell(\mathcal{H}(\mathcal{P}_{\text{raw}}))|$：下采样后点云大小

通常满足 $K \ll M \ll N$。

**压缩比**：

$$
\gamma = \frac{|\mathcal{P}_{\text{proc}}|}{|\mathcal{P}_{\text{raw}}|} \approx 0.05 \sim 0.15
$$

即点云大小降低至原来的 **5%~15%**。

## 3. 代码实现

### 3.1 高度过滤实现

```cpp
// 高度过滤：保留 [groundHeight_, roofHeight_] 范围内的点
pcl::PointCloud<pcl::PointXYZ>::Ptr heightFilteredCloud(...);
for (const pcl::PointXYZ &pt : worldCloud->points) {
  if (pt.z >= this->groundHeight_ && pt.z <= this->roofHeight_) {
    heightFilteredCloud->push_back(pt);
  }
}
```

### 3.2 体素下采样实现

```cpp
// 体素下采样：使用 PCL VoxelGrid 滤波器
pcl::VoxelGrid<pcl::PointXYZ> voxelFilter;
voxelFilter.setInputCloud(heightFilteredCloud);
voxelFilter.setLeafSize(this->voxelBaseLeafSize_, 
                       this->voxelBaseLeafSize_, 
                       this->voxelBaseLeafSize_);
voxelFilter.filter(*downsampledCloud);
```

### 3.3 范围过滤实现

```cpp
// 检测范围过滤
double rangeX = this->localLidarRange_.x();
double rangeY = this->localLidarRange_.y();

pcl::PointCloud<pcl::PointXYZ>::Ptr detectionRangeCloud(...);
for (const pcl::PointXYZ &pt : downsampledCloud->points) {
  double dx = std::abs(pt.x - this->positionLidar_(0));
  double dy = std::abs(pt.y - this->positionLidar_(1));
  
  if (dx <= rangeX && dy <= rangeY) {
    detectionRangeCloud->push_back(pt);
  }
}
```

### 3.4 完整流程实现

```cpp
// 完整预处理流程
pcl::PointCloud<pcl::PointXYZ>::Ptr dynamicDetector::preprocessWorldCloud(
    pcl::PointCloud<pcl::PointXYZ>::Ptr worldCloud) {
  
  // 1. 高度过滤
  pcl::PointCloud<pcl::PointXYZ>::Ptr heightFilteredCloud(...);
  for (const pcl::PointXYZ &pt : worldCloud->points) {
    if (pt.z >= this->groundHeight_ && pt.z <= this->roofHeight_) {
      heightFilteredCloud->push_back(pt);
    }
  }
  
  // 2. 体素下采样
  pcl::PointCloud<pcl::PointXYZ>::Ptr downsampledCloud(...);
  pcl::VoxelGrid<pcl::PointXYZ> voxelFilter;
  voxelFilter.setInputCloud(heightFilteredCloud);
  voxelFilter.setLeafSize(this->voxelBaseLeafSize_, ...);
  voxelFilter.filter(*downsampledCloud);
  
  // 3. 范围过滤
  pcl::PointCloud<pcl::PointXYZ>::Ptr detectionRangeCloud(...);
  for (const pcl::PointXYZ &pt : downsampledCloud->points) {
    double dx = std::abs(pt.x - this->positionLidar_(0));
    double dy = std::abs(pt.y - this->positionLidar_(1));
    if (dx <= rangeX && dy <= rangeY) {
      detectionRangeCloud->push_back(pt);
    }
  }
  
  return detectionRangeCloud;
}
```

## 4. 参数配置

### 4.1 参数表

| 参数 | 符号 | 典型值 | 作用 |
|------|------|--------|------|
| 地面高度 | $h_{\min}$ | -0.5 m | 过滤地面点 |
| 天花板高度 | $h_{\max}$ | 3.0 m | 过滤天花板点 |
| 体素边长 | $\ell$ | 0.1 m | 控制降采样程度 |
| 检测范围 | $r_x, r_y$ | 10 m | 有效检测区域 |
| 缓冲距离 | $\delta$ | 2 m | 静态地图缓冲 |

### 4.2 参数影响

**体素边长 $\ell$ 的影响**：

| $\ell$ | 压缩比 $\gamma$ | 误差 $d_{\max}$ | 计算时间 |
|--------|----------------|----------------|----------|
| 0.05 m | ~20% | 0.043 m | 高 |
| 0.10 m | ~10% | 0.087 m | 中 |
| 0.20 m | ~5% | 0.173 m | 低 |

**权衡原则**：$\ell$ 越小，保留的几何细节越多，但计算量越大；$\ell$ 越大，计算效率越高，但可能丢失重要特征。
