# 静态地图数学公式

## 1. 算法流程

静态地图模块用于从动态场景中分离静态环境，为动态物体检测提供稳定的背景参考。算法主要包含四个步骤：

1. **静态点云累积**（公式 1）：将多帧点云在世界坐标系下累积到体素网格，形成静态地图
2. **空间自适应静态判别**（公式 1.5）：根据点到传感器的距离动态调整静态判定阈值
3. **动态保护区域**（公式 2）：为已识别的动态物体构建保护区域，避免误删除
4. **射线投射过滤**（公式 3）：通过射线投射检测被动态物体遮挡的静态点并移除

**总公式**（引用子模块）：
$$
\mathcal{M}_{\text{static}}(t) = \left[\mathcal{M}_{\text{static}}(t-1) \cup \mathcal{A}(\mathcal{P}_t, t)\right] \setminus \mathcal{R}\left(\mathcal{M}_{\text{static}}(t-1), \mathcal{P}_t, \mathcal{B}(\mathcal{D}_t)\right)
$$

其中：
- $\mathcal{M}_{\text{static}}(t)$ 是 $t$ 时刻的静态地图
- $\mathcal{A}(\mathcal{P}_t, t)$ 是**静态点云累积函数**（公式 1），将新点云 $\mathcal{P}_t$ 累积到体素网格并判定静态点
- $\mathcal{B}(\mathcal{D}_t)$ 是**动态保护区域函数**（公式 2），为动态物体集合 $\mathcal{D}_t$ 构建保护区域
- $\mathcal{R}(\mathcal{M}, \mathcal{P}, \mathcal{B})$ 是**射线投射过滤函数**（公式 3），检测被遮挡的静态点（跳过保护区域）

---

## 2. 核心公式

### 2.1 坐标系定义

静态地图在**世界坐标系**（map frame）下维护，所有点云数据经过运动补偿后转换到世界坐标系。

**符号约定**：
- 上标 $w$ 表示世界坐标系（world/map frame）
- 上标 $s$ 表示传感器坐标系（sensor/lidar frame）
- 下标 $t$ 表示时间步

**记忆技巧**：
- "w" = world（世界坐标系，固定不动）
- "s" = sensor（传感器坐标系，随机器人运动）

**示例**：
- $\mathbf{p}^w$ 表示点在世界坐标系下的坐标
- $\mathbf{p}^s_t$ 表示点在 $t$ 时刻传感器坐标系下的坐标

---

### 2.2 静态点云累积（公式 1）

静态地图通过体素网格（Voxel Grid）维护，每个体素存储点云统计信息（观测次数、最后观测时间）。

**公式 1：静态点云累积函数**
$$
\begin{aligned}
\mathcal{A}(\mathcal{P}_t, t) = \Big\{ \mathbf{p}^w \in \mathcal{P}_t \mid & \mathcal{V}\left(\mathbf{i}(\mathbf{p}^w)\right).\text{count} \geq N_{\text{thresh}} \\
& \land \, t - \mathcal{V}\left(\mathbf{i}(\mathbf{p}^w)\right).\text{last}_{\text{seen}} \leq T_{\text{expire}} \Big\}
\end{aligned}
$$

其中体素索引函数：
$$
\mathbf{i}(\mathbf{p}^w) = \left[ \frac{\mathbf{p}^w - \mathbf{p}_{\text{origin}}}{s_{\text{voxel}}} \right]
$$

**公式解释**：
- 将点云 $\mathcal{P}_t$ 中的每个点 $\mathbf{p}^w$ 映射到体素索引 $\mathbf{i}(\mathbf{p}^w)$
- 累积体素观测次数：$\mathcal{V}(\mathbf{i}).\text{count} \leftarrow \mathcal{V}(\mathbf{i}).\text{count} + 1$
- 更新观测时间：$\mathcal{V}(\mathbf{i}).\text{last\_seen} \leftarrow t$
- **静态判定**：观测次数 $\geq N_{\text{thresh}}$ 的体素被认为是静态点
- **老化机制**：超过 $T_{\text{expire}}$ 时间未观测到的点会被移除

**变量说明**：

| 变量 | 含义 | 单位 |
|------|------|------|
| $\mathcal{P}_t$ | $t$ 时刻的输入点云 | - |
| $\mathbf{p}^w$ | 点在世界坐标系下的坐标 | m |
| $\mathbf{p}_{\text{origin}}$ | 体素网格原点 | m |
| $s_{\text{voxel}}$ | 体素大小 | m |
| $\mathcal{V}(\mathbf{i})$ | 索引为 $\mathbf{i}$ 的体素 | - |
| $N_{\text{thresh}}$ | 静态点判定阈值 | - |
| $T_{\text{expire}}$ | 过期时间阈值 | s |

**数值示例**：
- 体素大小：$s_{\text{voxel}} = 0.1$ m
- 静态阈值：$N_{\text{thresh}} = 3$（点被观测到3次以上认为是静态）
- 过期时间：$T_{\text{expire}} = 5.0$ s（超过此时间未观测到的点会被移除）

---

### 2.3 空间自适应静态判别（公式 1.5）

考虑到激光雷达点云分布的距离非均匀性与稀疏性特征，本算法设计了空间自适应的静态判别模型。该模型构建了基于距离梯度的置信度自适应函数，在近场区域通过高置信度阈值抑制传感器高频噪声，在远场区域通过松弛约束以保障弱纹理区域的特征召回率，实现了全场感知的一致性。

**公式 1.5：距离自适应阈值函数**
$$
N_{\text{thresh}}(\mathbf{p}^w) = \max\left(N_{\text{min}}, N_{\text{base}} - \left[ \frac{d(\mathbf{p}^w)}{d_{\text{step}}} \right]\right)
$$

其中点到传感器的距离：
$$
d(\mathbf{p}^w) = \sqrt{(p_x^w - p_{\text{sensor}}^x)^2 + (p_y^w - p_{\text{sensor}}^y)^2}
$$

**公式解释**：
- 静态判定阈值 $N_{\text{thresh}}$ 不再是固定值，而是根据点到传感器的距离 $d(\mathbf{p}^w)$ 动态调整
- **近场高阈值**：距离 $< 5$ m 时，使用基准阈值 $N_{\text{base}}$（通常为 5），抑制传感器噪声
- **远场松弛约束**：距离每增加 $d_{\text{step}}$ m，阈值降低 1，补偿点云稀疏性
- **最小阈值保护**：阈值不低于 $N_{\text{min}}$（通常为 2），避免过度松弛导致误判

**分段阈值示例**（$N_{\text{base}} = 5$，$N_{\text{min}} = 2$，$d_{\text{step}} = 5$ m）：

| 距离范围 | 距离平方 $d^2$ | 阈值 $N_{\text{thresh}}$ | 物理意义 |
|---------|---------------|------------------------|---------|
| $d < 5$ m | $d^2 < 25$ | 5 | 近场：高阈值抑制噪声 |
| $5 \leq d < 10$ m | $25 \leq d^2 < 100$ | 4 | 中场：适度降低阈值 |
| $10 \leq d < 20$ m | $100 \leq d^2 < 400$ | 3 | 远场：进一步松弛 |
| $d \geq 20$ m | $d^2 \geq 400$ | 2 | 极远场：最小阈值保障召回率 |

**变量说明**：

| 变量 | 含义 | 典型值 | 单位 |
|------|------|--------|------|
| $N_{\text{thresh}}(\mathbf{p}^w)$ | 点 $\mathbf{p}^w$ 的自适应静态判定阈值 | 2-5 | - |
| $N_{\text{base}}$ | 基准阈值（近场） | 5 | - |
| $N_{\text{min}}$ | 最小阈值（远场保护） | 2 | - |
| $d(\mathbf{p}^w)$ | 点到传感器的水平距离 | - | m |
| $d_{\text{step}}$ | 距离分段步长 | 5 | m |
| $\mathbf{p}_{\text{sensor}}$ | 传感器在世界坐标系下的位置 | - | m |

**设计原理**：
1. **近场噪声抑制**：激光雷达在近距离（< 5m）点云密集但噪声较大，需要更多观测次数（5次）才能确认为静态点
2. **远场稀疏补偿**：远距离（> 20m）点云稀疏，降低阈值至 2 次观测即可判定，提高弱纹理区域的特征召回率
3. **平滑过渡**：中间距离采用线性递减策略，避免阈值突变导致的不连续性

**数值示例**：
- 近场点（3m）：需要观测 5 次才判定为静态
- 中场点（8m）：需要观测 4 次
- 远场点（15m）：需要观测 3 次
- 极远场点（25m）：需要观测 2 次

### 2.4 动态保护区域（公式 2）

为避免误删除动态物体区域的静态点，为所有动态物体构建保护区域。

**公式 2：动态保护区域函数**
$$
\mathcal{B}(\mathcal{D}_t) = \bigcup_{i=1}^{|\mathcal{D}_t|} \left\{ \mathbf{p}^w \mid \max_{k \in \{x,y,z\}} \left( \frac{|p_k^w - B_i^k|}{B_i^{w_k}/2 + \delta_{\text{margin}}} \right) \leq 1 \right\}
$$

**公式解释**：
- 对于 $t$ 时刻的所有动态物体集合 $\mathcal{D}_t$（共 $|\mathcal{D}_t|$ 个边界框）
- 每个边界框 $i$ 的保护区域是其原始边界框在 x、y、z 三个方向各扩展 $\delta_{\text{margin}}$ 后的区域
- 所有动态物体的保护区域取并集，形成总保护区域 $\mathcal{B}(\mathcal{D}_t)$
- 在射线投射过滤（公式 3）中，位于 $\mathcal{B}(\mathcal{D}_t)$ 内的静态点不会被移除

**等价形式**（更直观）：
$$
\mathbf{p}^w \in \mathcal{B}_i \iff \begin{cases}
|p_x^w - B_i^x| \leq \frac{B_i^{w_x}}{2} + \delta_{\text{margin}} \\
|p_y^w - B_i^y| \leq \frac{B_i^{w_y}}{2} + \delta_{\text{margin}} \\
|p_z^w - B_i^z| \leq \frac{B_i^{w_z}}{2} + \delta_{\text{margin}}
\end{cases}
$$

**变量说明**：

| 变量 | 含义 | 单位 |
|------|------|------|
| $\mathcal{D}_t$ | $t$ 时刻的动态物体集合 | - |
| $\mathcal{B}(\mathcal{D}_t)$ | 总保护区域 | - |
| $(B_i^x, B_i^y, B_i^z)$ | 第 $i$ 个边界框中心坐标 | m |
| $(B_i^{w_x}, B_i^{w_y}, B_i^{w_z})$ | 第 $i$ 个边界框尺寸 | m |
| $\delta_{\text{margin}}$ | 保护边界扩展量 | m |

**数值示例**：
- 保护边界：$\delta_{\text{margin}} = 0.1$ m
- 动态物体边界框：中心 $(2.0, 3.0, 1.0)$ m，尺寸 $(0.5, 0.5, 1.8)$ m
- 保护区域：$x \in [1.65, 2.35]$，$y \in [2.65, 3.35]$，$z \in [0.0, 2.0]$ m

### 2.5 射线投射过滤（公式 3）

射线投射用于检测被动态物体遮挡的静态点，避免"幽灵点"残留。

**公式 3：射线投射过滤函数**
$$
\begin{aligned}
\mathcal{R}(\mathcal{M}, \mathcal{P}_t, \mathcal{B}) = \Big\{ \mathbf{p}_s^w \in \mathcal{M} \mid & \mathbf{p}_s^w \notin \mathcal{B} \\
& \land \, \exists \mathbf{p}_n^w \in \mathcal{P}_t: \left\| \mathbf{d}_n - \mathbf{d}_s \right\| < \delta_{\text{angle}} \\
& \land \, \|\mathbf{p}_n^w - \mathbf{p}_{\text{sensor}}^w\| < \|\mathbf{p}_s^w - \mathbf{p}_{\text{sensor}}^w\| - \epsilon \Big\}
\end{aligned}
$$

其中射线方向向量：
$$
\mathbf{d}_n = \frac{\mathbf{p}_n^w - \mathbf{p}_{\text{sensor}}^w}{\|\mathbf{p}_n^w - \mathbf{p}_{\text{sensor}}^w\|}, \quad \mathbf{d}_s = \frac{\mathbf{p}_s^w - \mathbf{p}_{\text{sensor}}^w}{\|\mathbf{p}_s^w - \mathbf{p}_{\text{sensor}}^w\|}
$$

**公式解释**：
- 对于静态地图中的每个点 $\mathbf{p}_s^w$，检查是否被当前点云 $\mathcal{P}_t$ 遮挡
- **保护条件**：如果静态点在动态保护区域 $\mathcal{B}$ 内（$\mathbf{p}_s^w \in \mathcal{B}$），则跳过射线投射检测
- **遮挡条件**：存在新点云点 $\mathbf{p}_n^w$ 满足：
  - 与静态点在同一射线上（方向向量差 $< \delta_{\text{angle}}$）
  - 距离传感器更近（距离差 $> \epsilon$）
- 满足遮挡条件的静态点会被移除

**变量说明**：

| 变量 | 含义 | 单位 |
|------|------|------|
| $\mathcal{M}$ | 当前静态地图 | - |
| $\mathcal{P}_t$ | $t$ 时刻的输入点云 | - |
| $\mathcal{B}$ | 动态保护区域（公式 2） | - |
| $\mathbf{p}_s^w$ | 静态地图中的点 | m |
| $\mathbf{p}_n^w$ | 新点云中的点 | m |
| $\mathbf{p}_{\text{sensor}}^w$ | 传感器在世界坐标系下的位置 | m |
| $\mathbf{d}_n, \mathbf{d}_s$ | 射线方向向量（单位向量） | - |
| $\epsilon$ | 遮挡判定阈值（避免噪声） | m |
| $\delta_{\text{angle}}$ | 射线方向判定阈值 | - |

**数值示例**：
- 遮挡阈值：$\epsilon = 0.2$ m
- 方向阈值：$\delta_{\text{angle}} = 0.1$（约 5.7°）
- 如果新点云点距离传感器 5.0 m，静态点距离 5.5 m，且两者在同一射线上（方向差 < 5.7°），则静态点被遮挡

## 3. 代码实现

### 3.1 静态地图更新（关键代码）

```cpp
// 更新静态地图（对应总公式）
void StaticPointFilter::updateMap(
    pcl::PointCloud<pcl::PointXYZ>::Ptr cloud,
    double currentTime,
    const Eigen::Vector3d& sensorPos,
    const std::vector<box3D>* protectedBoxes) {
  
  // 公式 1：静态点云累积 A(P_t, t)
  for (const auto& point : cloud->points) {
    Eigen::Vector3i voxelIdx = getVoxelIndex(point);  // 计算体素索引 i(p^w)
    voxelMap_[voxelIdx].count++;                      // 累积观测次数
    voxelMap_[voxelIdx].last_seen = currentTime;      // 更新观测时间
  }
  
  // 公式 2：动态保护区域 B(D_t)
  // protectedBoxes 即为动态物体集合 D_t
  
  // 公式 3：射线投射过滤 R(M, P_t, B)
  for (auto it = voxelMap_.begin(); it != voxelMap_.end(); ) {
    Eigen::Vector3d staticPoint = getVoxelCenter(it->first);
    
    // 检查是否在保护区域内（p_s^w ∈ B）
    bool inProtectedArea = false;
    if (protectedBoxes) {
      for (const auto& box : *protectedBoxes) {
        if (isPointInBox(staticPoint, box)) {
          inProtectedArea = true;
          break;
        }
      }
    }
    
    // 如果不在保护区域，执行射线投射检测
    if (!inProtectedArea) {
      if (isOccluded(staticPoint, cloud, sensorPos)) {
        it = voxelMap_.erase(it);  // 移除被遮挡的点
        continue;
      }
    }
    
    // 老化机制（公式 1 的一部分）
    if (currentTime - it->second.last_seen > expireTime_) {
      it = voxelMap_.erase(it);
    } else {
      ++it;
    }
  }
}
```

### 3.2 射线投射优化（DDA算法）

沿射线方向快速遍历体素网格，避免检查所有体素。

```cpp
// 射线投射遮挡检测（对应公式 3）
bool StaticPointFilter::isOccluded(
    const Eigen::Vector3d& staticPoint,
    pcl::PointCloud<pcl::PointXYZ>::Ptr cloud,
    const Eigen::Vector3d& sensorPos) {
  
  // 计算静态点的射线方向 d_s
  Eigen::Vector3d dir_s = (staticPoint - sensorPos).normalized();
  double dist_s = (staticPoint - sensorPos).norm();
  
  // DDA体素遍历：沿射线方向检查新点云
  Eigen::Vector3d currentPos = sensorPos;
  double step = voxelSize * 0.5;  // 步长为体素大小的一半
  
  while ((currentPos - sensorPos).norm() < dist_s) {
    // 检查当前体素是否有新点云点
    for (const auto& point : cloud->points) {
      Eigen::Vector3d p_n(point.x, point.y, point.z);
      
      // 检查是否在当前体素附近
      if ((p_n - currentPos).norm() < voxelSize) {
        // 计算新点的射线方向 d_n
        Eigen::Vector3d dir_n = (p_n - sensorPos).normalized();
        double dist_n = (p_n - sensorPos).norm();
        
        // 检查是否在同一射线上（||d_n - d_s|| < δ_angle）
        if ((dir_n - dir_s).norm() < angleThreshold) {
          // 检查距离条件（dist_n < dist_s - ε）
          if (dist_n < dist_s - occlusionThreshold) {
            return true;  // 被遮挡
          }
        }
      }
    }
    currentPos += dir_s * step;
  }
  
  return false;  // 未被遮挡
}
```

## 4. 边界情况处理

| 情况 | 处理方法 |
|------|----------|
| 传感器位置异常 | 检查 `sensorPos` 是否有效（`isfinite`），无效则跳过更新 |
| 点云为空 | 直接返回，不执行射线投射 |
| 动态物体边界框为空 | 正常执行射线投射，无保护区域（$\mathcal{B} = \emptyset$） |
| 体素网格过大 | 限制地图范围（如 50m × 50m），超出范围的点不加入 |
| 射线投射耗时过长 | 使用体素遍历优化（DDA算法），避免检查所有点 |
| 数值精度问题 | 使用阈值 $\epsilon$ 和 $\delta_{\text{angle}}$ 避免浮点误差 |
