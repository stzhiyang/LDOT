# 多目标跟踪模块伪代码

```
输入: P_t (点云), Tracks_{t-1} (历史轨迹), dt (时间步长)
输出: Tracks_t (更新后的轨迹集合)
```

```python
function MultiObjectTracking(P_t, Tracks_{t-1}, dt):
    # 步骤1: 自适应聚类 (公式1)
    Clusters = []
    kdtree = BuildKDTree(P_t)
    for each point p_i in P_t:
        ε_adapt = ComputeAdaptiveRadius(p_i, p_sensor)
        neighbors = kdtree.RadiusSearch(p_i, ε_adapt)
        if |neighbors| >= N_min:
            cluster = ExpandCluster(p_i, neighbors, kdtree, ε_adapt, N_min)
            Clusters.append(ComputeClusterFeatures(cluster))
    
    # 步骤2: 异常边界框过滤 (公式2)
    ValidDetections = FilterBySize(Clusters, w_max)
    
    # 步骤3: 鲁棒数据关联 (公式3)
    M = |ValidDetections|, N = |Tracks_{t-1}|
    PredictedTracks = PredictAllTracks(Tracks_{t-1}, dt)
    
    CostMatrix = Matrix(M, N, fill=INF)
    for i = 1 to M, j = 1 to N:
        cost = ComputeAssociationCost(ValidDetections[i], PredictedTracks[j])
        if cost < γ_gate:
            CostMatrix[i][j] = cost
    
    Matches = HungarianAlgorithm(CostMatrix)
    
    # 步骤4: 几何特征分类 (公式4)
    for (det_idx, track_idx) in Matches:
        ClassifyAndSwitchModel(track, detection)
    
    # 步骤5: 自适应状态估计 (公式5-7)
    UpdatedTracks = []
    for (det_idx, track_idx) in Matches:
        ν = ComputeInnovation(detection, x_pred)
        K = ComputeKalmanGain(P_pred, R)
        x_updated = x_pred + K × ν
        P_updated = (I - K × H) × P_pred
        
        C_ν = ComputeInnovationCovariance(track.innovation_history)
        R_hat = EstimateObservationNoise(C_ν, P_pred)
        Q_hat = EstimateProcessNoise(C_ν, K, P_pred, R)
        track.R = (1-λ) × track.R + λ × R_hat
        track.Q = (1-λ) × track.Q + λ × Q_hat
        
        track.state = x_updated
        track.covariance = P_updated
        UpdatedTracks.append(track)
    
    # 步骤6: 轨迹管理
    Tracks_t = ManageTracks(UpdatedTracks, UnmatchedTracks, UnmatchedDetections)
    
    return Tracks_t
```

## 复杂度分析

**时间复杂度：**
- **聚类**：O(N log N)（KD-Tree构建 + 邻域搜索）
- **数据关联**：O(M × N + M³)（代价矩阵构建 + 匈牙利算法）
- **状态估计**：O(M × n³)（M个轨迹，n维状态空间的矩阵运算）
- **总复杂度**：O(N log N + M × N + M³ + M × n³)

**空间复杂度：**
- **点云存储**：O(N)
- **轨迹历史**：O(M × hist_size × N_cluster)
- **代价矩阵**：O(M × N)
- **总空间**：O(N + M × hist_size × N_cluster)

其中：
- N：点云点数（典型值：10,000-100,000）
- M：轨迹数量（典型值：5-50）
- n：状态向量维度（6-9维）
- N_cluster：每个聚类的平均点数（典型值：50-500）
