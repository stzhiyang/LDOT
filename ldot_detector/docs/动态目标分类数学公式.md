# 动态目标分类数学公式

## 1. 算法流程

动态目标分类模块负责判断跟踪的目标是否为动态物体。该模块通过分析点云的运动一致性和时间连续性，实现鲁棒的动静态物体判别。

算法主要分为三个步骤：

1. **强制动态判定**：基于历史动态频率快速判定
2. **点云运动一致性检查**：通过逐点速度计算和投票机制判断物体运动状态
3. **动态一致性检查**：通过时间连续性过滤偶然误判

**总公式**（引用子模块）：

$$
\text{IsDynamic}(i, t) = \mathcal{F}_{\text{force}}(i, t) \lor \left[\mathcal{F}_{\text{motion}}(i, t) \land \mathcal{F}_{\text{consist}}(i, t)\right]
$$

其中：
- $\mathcal{F}_{\text{force}}$ 对应公式 1（强制动态判定）
- $\mathcal{F}_{\text{motion}}$ 对应公式 2（点云运动一致性）
- $\mathcal{F}_{\text{consist}}$ 对应公式 3（动态一致性检查）
- $i$ 表示第 $i$ 个跟踪目标
- $t$ 表示当前时刻

## 2. 核心公式

### 2.1 坐标系与符号定义

**坐标系**：
- 世界坐标系 $\{W\}$：固定在地面的全局坐标系，所有计算在此坐标系下进行
- 点云坐标：$\mathbf{p}_j^t = \left[x_j^t, y_j^t, z_j^t\right]^T \in \mathbb{R}^3$

**符号约定**：
- **上标**：表示时间帧，如 $t$ 表示当前帧，$t-\Delta t$ 表示历史帧
- **下标**：表示索引，如 $i$ 表示第 $i$ 个目标，$j$ 表示第 $j$ 个点
- **粗体**：表示向量或矩阵，如 $\mathbf{v}$ 表示速度向量

**记忆技巧**：
- $\mathbf{v}_{\text{KF}}^{i,t}$：第 $i$ 个目标在时刻 $t$ 的卡尔曼滤波器（KF）估计速度
- $\mathbf{v}_{\text{box}}^{i,t}$：第 $i$ 个目标在时刻 $t$ 的边界框速度
- $\mathbf{v}_j^{i,t}$：第 $i$ 个目标的第 $j$ 个点在时刻 $t$ 的速度

**具体例子**：
- 目标 $i=1$，当前帧 $t=10$，历史帧 $t-\Delta t = 9$
- 点云点 $\mathbf{p}_5^{10} = \left[2.3, 1.5, 0.8\right]^T$ 表示第 5 个点在第 10 帧的坐标

### 2.2 强制动态判定

**公式 1：强制动态判定**

$$
\mathcal{F}_{\text{force}}(i, t) = \begin{cases}
\text{True}, & \text{if } N_{\text{dyna}}^{i,t} \geq N_{\text{thresh}} \land \|\mathbf{v}_{\text{KF}}^{i,t}\| \geq 0.8 \cdot v_{\text{thresh}} \\
\text{False}, & \text{otherwise}
\end{cases}
$$

其中：

$$
N_{\text{dyna}}^{i,t} = \sum_{k=1}^{N_{\text{check}}} \mathbb{1}\left[\text{IsDynamic}(i, t-k) = \text{True}\right]
$$

**变量说明**：

| 符号 | 含义 | 典型值 |
|------|------|--------|
| $N_{\text{dyna}}^{i,t}$ | 目标 $i$ 在过去 $N_{\text{check}}$ 帧中被判定为动态的次数 | 0-10 |
| $N_{\text{thresh}}$ | 强制动态判定的帧数阈值 | 5 |
| $N_{\text{check}}$ | 检查的历史帧数范围 | 10 |
| $\mathbf{v}_{\text{KF}}^{i,t}$ | 卡尔曼滤波器估计的速度向量 | $\left[v_x, v_y, v_z\right]^T$ |
| $v_{\text{thresh}}$ | 动态速度阈值 | 0.5 m/s |
| $\mathbb{1}\left[\cdot\right]$ | 指示函数，条件为真时返回 1，否则返回 0 | - |

**公式解释**：

如果一个目标在过去 $N_{\text{check}}=10$ 帧中有至少 $N_{\text{thresh}}=5$ 帧被判定为动态，且当前速度 $\|\mathbf{v}_{\text{KF}}^{i,t}\| \geq 0.4$ m/s（$0.8 \times 0.5$），则强制判定为动态。这避免了已确认的动态物体被误判为静态。

**数值示例**：

假设目标 $i=1$ 在过去 10 帧的动态判定结果为：`[True, True, False, True, True, True, False, True, True, False]`

- $N_{\text{dyna}}^{1,t} = 7 \geq 5$ ✓
- $\|\mathbf{v}_{\text{KF}}^{1,t}\| = 0.6 \geq 0.4$ ✓
- 结果：$\mathcal{F}_{\text{force}}(1, t) = \text{True}$（强制判定为动态）

### 2.3 点云运动一致性检查

**公式 2：点云运动一致性判定**

$$
\mathcal{F}_{\text{motion}}(i, t) = \begin{cases}
\text{True}, & \text{if } \|\mathbf{v}_{\text{KF}}^{i,t}\| \geq 2 v_{\text{thresh}} \land s_i < s_{\text{small}} \\
\text{True}, & \text{if } R_{\text{vote}}^{i,t} \geq R_{\text{vote}}^{\text{adapt}}(i) \land \|\mathbf{v}_{\text{KF}}^{i,t}\| \geq v_{\text{thresh}}^{\text{adapt}}(i) \\
\text{False}, & \text{otherwise}
\end{cases}
$$

其中投票率 $R_{\text{vote}}^{i,t}$ 和自适应阈值定义为：

$$
R_{\text{vote}}^{i,t} = \frac{N_{\text{vote}}^{i,t}}{N_{\text{valid}}^{i,t}}, \quad
R_{\text{vote}}^{\text{adapt}}(i) = \begin{cases}
0.3, & \text{if } s_i < s_{\text{small}} \text{ or } \text{IsUAV}(i) \\
0.5, & \text{otherwise}
\end{cases}
$$

$$
v_{\text{thresh}}^{\text{adapt}}(i) = \begin{cases}
1.5 \cdot v_{\text{thresh}}, & \text{if } s_i < s_{\text{small}} \text{ or } \text{IsUAV}(i) \\
v_{\text{thresh}}, & \text{otherwise}
\end{cases}
$$

投票数 $N_{\text{vote}}^{i,t}$ 和有效点数 $N_{\text{valid}}^{i,t}$ 的计算：

$$
N_{\text{vote}}^{i,t} = \sum_{j=1}^{M_i^t} \mathbb{1}\left[\|\mathbf{v}_j^{i,t}\| > v_{\text{thresh}} \land \cos\theta_j^{i,t} > 0\right]
$$

$$
N_{\text{valid}}^{i,t} = \sum_{j=1}^{M_i^t} \mathbb{1}\left[\cos\theta_j^{i,t} > 0\right]
$$

其中点速度 $\mathbf{v}_j^{i,t}$ 和速度方向相似度 $\cos\theta_j^{i,t}$ 定义为：

$$
\mathbf{v}_j^{i,t} = \frac{\mathbf{p}_j^{i,t} - \mathbf{p}_{\text{nn}(j)}^{i,t-\Delta t}}{\Delta t}, \quad
\cos\theta_j^{i,t} = \frac{\mathbf{v}_j^{i,t} \cdot \mathbf{v}_{\text{box}}^{i,t}}{\|\mathbf{v}_j^{i,t}\| \cdot \|\mathbf{v}_{\text{box}}^{i,t}\|}
$$

边界框速度 $\mathbf{v}_{\text{box}}^{i,t}$ 定义为：

$$
\mathbf{v}_{\text{box}}^{i,t} = \frac{\mathbf{c}^{i,t} - \mathbf{c}^{i,t-\Delta t}}{\Delta t}
$$

**变量说明**：

| 符号 | 含义 | 典型值 |
|------|------|--------|
| $R_{\text{vote}}^{i,t}$ | 目标 $i$ 在时刻 $t$ 的动态投票率 | 0-1 |
| $N_{\text{vote}}^{i,t}$ | 投票为动态的点数 | 0-$M_i^t$ |
| $N_{\text{valid}}^{i,t}$ | 有效点数（速度方向一致的点） | 0-$M_i^t$ |
| $M_i^t$ | 目标 $i$ 在时刻 $t$ 的点云点数 | 10-1000 |
| $\mathbf{v}_j^{i,t}$ | 第 $j$ 个点的速度向量 | $\left[v_x, v_y, v_z\right]^T$ |
| $\mathbf{p}_{\text{nn}(j)}^{i,t-\Delta t}$ | 点 $j$ 在历史帧中的最近邻点 | - |
| $\cos\theta_j^{i,t}$ | 点速度与边界框速度的余弦相似度 | -1 到 1 |
| $\mathbf{v}_{\text{box}}^{i,t}$ | 边界框中心速度 | $\left[v_x, v_y, v_z\right]^T$ |
| $\mathbf{c}^{i,t}$ | 边界框中心坐标 | $\left[x, y, z\right]^T$ |
| $\Delta t$ | 时间步长 | 0.1 s |
| $s_i$ | 目标 $i$ 的最大尺寸 | $\max(w_x, w_y, w_z)$ |
| $s_{\text{small}}$ | 小型物体尺寸阈值 | 1.0 m |

**公式解释**：

1. **快速判定**：如果物体尺寸小于 1.0m 且速度超过 1.0 m/s（$2 \times 0.5$），直接判定为动态
2. **投票机制**：计算点云中每个点的速度，如果速度超过阈值且方向与边界框一致，则投票为动态
3. **自适应阈值**：小型物体（如无人机）使用更宽松的投票率阈值（0.3）和更高的速度阈值（0.75 m/s）

**数值示例**：

假设目标 $i=2$ 是一个小型物体（$s_2 = 0.8$ m < 1.0 m）：

- 点云点数：$M_2^t = 50$
- 投票为动态的点数：$N_{\text{vote}}^{2,t} = 18$
- 有效点数：$N_{\text{valid}}^{2,t} = 45$（5 个点速度方向相反被过滤）
- 投票率：$R_{\text{vote}}^{2,t} = 18/45 = 0.4$
- 自适应阈值：$R_{\text{vote}}^{\text{adapt}}(2) = 0.3$（小型物体）
- 卡尔曼速度：$\|\mathbf{v}_{\text{KF}}^{2,t}\| = 0.8$ m/s
- 自适应速度阈值：$v_{\text{thresh}}^{\text{adapt}}(2) = 0.75$ m/s

判定结果：
- $R_{\text{vote}}^{2,t} = 0.4 \geq 0.3$ ✓
- $\|\mathbf{v}_{\text{KF}}^{2,t}\| = 0.8 \geq 0.75$ ✓
- 结果：$\mathcal{F}_{\text{motion}}(2, t) = \text{True}$（判定为动态候选）

### 2.4 动态一致性检查

**公式 3：动态一致性判定**

$$
\mathcal{F}_{\text{consist}}(i, t) = \begin{cases}
\text{True}, & \text{if } N_{\text{consist}}^{i,t} = N_{\text{consist}}^{\text{thresh}} \\
\text{False}, & \text{otherwise}
\end{cases}
$$

其中一致性计数 $N_{\text{consist}}^{i,t}$ 定义为：

$$
N_{\text{consist}}^{i,t} = \sum_{k=0}^{N_{\text{consist}}^{\text{thresh}}-1} \mathbb{1}\left[\mathcal{F}_{\text{motion}}(i, t-k) = \text{True} \lor \text{IsDynamic}(i, t-k) = \text{True}\right]
$$

**变量说明**：

| 符号 | 含义 | 典型值 |
|------|------|--------|
| $N_{\text{consist}}^{i,t}$ | 目标 $i$ 在过去 $N_{\text{consist}}^{\text{thresh}}$ 帧中被判定为动态候选或动态的次数 | 0-3 |
| $N_{\text{consist}}^{\text{thresh}}$ | 动态一致性检查的帧数阈值 | 3 |

**公式解释**：

只有当目标在连续 $N_{\text{consist}}^{\text{thresh}}=3$ 帧中都被判定为动态候选或动态时，才最终确认为动态。这避免了偶然的误判。

**数值示例**：

假设目标 $i=3$ 在过去 3 帧的判定结果为：

| 帧 | $\mathcal{F}_{\text{motion}}$ | IsDynamic | 计入一致性 |
|----|-------------------------------|-----------|-----------|
| $t$ | True | False | ✓ |
| $t-1$ | True | False | ✓ |
| $t-2$ | True | False | ✓ |

- $N_{\text{consist}}^{3,t} = 3 = N_{\text{consist}}^{\text{thresh}}$ ✓
- 结果：$\mathcal{F}_{\text{consist}}(3, t) = \text{True}$（通过一致性检查）
- 最终：$\text{IsDynamic}(3, t) = \text{True}$（确认为动态）

## 3. 代码实现

### 3.1 强制动态判定

```cpp
// 强制动态判定（公式 1）
int dynaFrames = 0;
if (int(this->boxHist_[i].size()) > this->forceDynaCheckRange_) {
  // 计算 N_dyna^{i,t}
  for (int j = 1; j < this->forceDynaCheckRange_ + 1; ++j) {
    if (this->boxHist_[i][j].is_dynamic) {
      ++dynaFrames;
    }
  }
}

// 获取卡尔曼滤波器速度 v_KF^{i,t}
Eigen::Vector3d Vkf(0., 0., 0.);
Eigen::VectorXd state = this->filters_[i]->getState();
int dim = state.size();

if (dim == 6) {
  // 3D CV 模型: [x, y, z, vx, vy, vz]
  Vkf(0) = state(3);
  Vkf(1) = state(4);
  Vkf(2) = state(5);
} else if (dim == 7) {
  // 7维模型（Human CA 或 Vehicle CTRA）
  bool isVehicle = this->boxHist_[i][0].is_che;
  if (isVehicle) {
    // CTRA: [x, y, z, v, a, yaw, yaw_rate]
    double v = state(3);
    double yaw = state(5);
    Vkf(0) = v * cos(yaw);
    Vkf(1) = v * sin(yaw);
  } else {
    // Human CA: [x, y, z, vx, vy, ax, ay]
    Vkf(0) = state(3);
    Vkf(1) = state(4);
  }
} else if (dim == 9) {
  // 3D CA 模型 (UAV): [x, y, z, vx, vy, vz, ax, ay, az]
  Vkf(0) = state(3);
  Vkf(1) = state(4);
  Vkf(2) = state(5);
}

double velNorm = Vkf.norm();

// 应用公式 1
if (dynaFrames >= this->forceDynaFrames_ && 
    velNorm >= this->dynaVelThresh_ * 0.8) {
  this->boxHist_[i][0].is_dynamic = true;
  dynamicBBoxesTemp.push_back(this->boxHist_[i][0]);
  continue;  // 跳过后续计算
}
```

### 3.2 点云运动一致性检查

```cpp
// 计算边界框速度 v_box^{i,t}（公式 2）
Eigen::Vector3d Vbox(0., 0., 0.);
int curFrameGap = 1;  // Δt = 1 帧

Vbox(0) = (this->boxHist_[i][0].x - this->boxHist_[i][curFrameGap].x) / 
          (this->dt_ * curFrameGap);
Vbox(1) = (this->boxHist_[i][0].y - this->boxHist_[i][curFrameGap].y) / 
          (this->dt_ * curFrameGap);
Vbox(2) = (this->boxHist_[i][0].z - this->boxHist_[i][curFrameGap].z) / 
          (this->dt_ * curFrameGap);

// 获取当前帧和历史帧的点云
std::vector<Eigen::Vector3d> currPc = this->pcHist_[i][0];
std::vector<Eigen::Vector3d> prevPc = this->pcHist_[i][curFrameGap];

int numPoints = currPc.size();  // M_i^t
int votes = 0;                  // N_vote^{i,t}

// 逐点计算速度和投票
for (size_t j = 0; j < currPc.size(); ++j) {
  double minDist = this->classificationMinNeighborDist_;
  Eigen::Vector3d nearestVect;
  
  // 寻找最近邻点 p_nn(j)^{i,t-Δt}
  for (size_t k = 0; k < prevPc.size(); k++) {
    double dist = (currPc[j] - prevPc[k]).norm();
    if (abs(dist) < minDist) {
      minDist = dist;
      nearestVect = currPc[j] - prevPc[k];
    }
  }
  
  // 计算点速度 v_j^{i,t}
  Eigen::Vector3d Vcur = nearestVect / (this->dt_ * curFrameGap);
  
  // 对于人物/车辆，忽略 Z 轴速度
  if (!(this->boxHist_[i][0].is_uav || this->boxHist_[i][0].is_else)) {
    Vcur(2) = 0;
  }
  
  // 计算速度方向相似度 cos(θ_j^{i,t})
  double velSim = Vcur.dot(Vbox) / (Vcur.norm() * Vbox.norm());
  
  // 过滤方向相反的点（更新 N_valid^{i,t}）
  if (velSim < 0) {
    --numPoints;
  } else {
    // 投票判定
    if (Vcur.norm() > this->dynaVelThresh_) {
      ++votes;
    }
  }
}

// 计算投票率 R_vote^{i,t}
double voteRatio = (numPoints > 0) ? double(votes) / double(numPoints) : 0;

// 获取物体尺寸（用于自适应阈值）
double x_width = this->boxHist_[i][0].x_width;
double y_width = this->boxHist_[i][0].y_width;
double z_width = this->boxHist_[i][0].z_width;
double max_size = std::max({x_width, y_width, z_width});

// 判断是否为小型物体
bool is_small_object = (max_size < this->classifyUAVMaxSize_);

bool is_dynamic_candidate = false;

// 应用公式 2（自适应阈值）
if (is_small_object || this->boxHist_[i][0].is_uav) {
  // 快速判定：速度非常高
  if (velNorm >= this->dynaVelThresh_ * 2) {
    this->boxHist_[i][0].is_dynamic = true;
  } 
  // 小型物体判定：宽松的投票率 + 较高的速度阈值
  else if (velNorm >= this->dynaVelThresh_ * 1.5) {
    is_dynamic_candidate = (voteRatio >= 0.3);
  }
} else {
  // 正常判定逻辑
  is_dynamic_candidate = (voteRatio >= this->dynaVoteThresh_ && 
                          velNorm >= this->dynaVelThresh_);
}
```

### 3.3 动态一致性检查

```cpp
// 应用公式 3
if (is_dynamic_candidate) {
  this->boxHist_[i][0].is_dynamic_candidate = true;
  
  // 计算 N_consist^{i,t}
  int dynaConsistCount = 0;
  if (int(this->boxHist_[i].size()) >= this->dynamicConsistThresh_) {
    for (int j = 0; j < this->dynamicConsistThresh_; ++j) {
      if (this->boxHist_[i][j].is_dynamic_candidate ||
          this->boxHist_[i][j].is_dynamic) {
        ++dynaConsistCount;
      }
    }
  }
  
  // 只有连续多帧都是动态候选，才最终判定为动态
  if (dynaConsistCount == this->dynamicConsistThresh_) {
    this->boxHist_[i][0].is_dynamic = true;
    dynamicBBoxesTemp.push_back(this->boxHist_[i][0]);
  }
}
```

**性能优化技巧**：

1. **早期退出**：强制动态判定通过后直接跳过后续计算
2. **最近邻搜索优化**：可以使用 KD-Tree 加速（当前使用暴力搜索）
3. **向量化计算**：使用 Eigen 库的向量化操作提高效率

## 4. 边界情况处理

| 情况 | 处理方法 |
|------|---------|
| 历史帧数不足（< 2 帧） | 跳过该目标，不进行动态判定 |
| 点云为空或点数过少 | 投票率设为 0，依赖卡尔曼滤波器速度判定 |
| 最近邻距离过大 | 该点不参与投票，减少 $N_{\text{valid}}$ |
| 速度方向相反（$\cos\theta < 0$） | 认为是噪声，从有效点数中排除 |
| 卡尔曼滤波器未初始化 | 跳过该目标，不进行动态判定 |
| 物体尺寸异常（过大或过小） | 使用自适应阈值策略调整判定标准 |
| 速度为零或接近零 | 直接判定为静态，跳过投票机制 |
