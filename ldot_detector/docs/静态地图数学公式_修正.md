# 静态地图数学公式

## 1. 算法流程

静态地图模块用于从动态场景中分离静态环境，为动态物体检测提供稳定的背景参考。算法主要包含三个步骤：

1. **静态点云累积**（公式 1）：将多帧点云在世界坐标系下累积到体素网格，形成静态地图
2. **空间自适应静态判别**（公式 1.5）：根据点到传感器的距离动态调整静态判定阈值
3. **射线投射递减**（公式 2）：对保护区内的射线终点和路径体素进行递减，防止动态物体累积

**总公式**（引用子模块）：
$
\mathcal{M}_{\text{static}}(t) = \left[\mathcal{M}_{\text{static}}(t-1) \cup \mathcal{A}(\mathcal{P}_t, t)\right] \setminus \mathcal{R}(\mathcal{P}_t, \mathcal{B}(\mathcal{D}_t))
$

其中：
- $\mathcal{M}_{\text{static}}(t)$ 是 $t$ 时刻的静态地图
- $\mathcal{A}(\mathcal{P}_t, t)$ 是**静态点云累积函数**（公式 1），将新点云累积到体素网格
- $\mathcal{R}(\mathcal{P}_t, \mathcal{B})$ 是**射线投射递减函数**（公式 2），对保护区内的射线终点和路径体素递减
- $\mathcal{B}(\mathcal{D}_t)$ 是动态保护区域，为动态物体集合 $\mathcal{D}_t$ 构建的边界框区域
- 前半部分 $[\cdot \cup \mathcal{A}]$ 表示累积操作，后半部分 $\setminus \mathcal{R}$ 表示削减操作

## 2. 核心公式

### 2.1 坐标系定义

静态地图在**世界坐标系**（map frame）下维护，所有点云数据经过运动补偿后转换到世界坐标系。

**符号约定**：
- 上标 $w$ 表示世界坐标系（world/map frame）
- 上标 $s$ 表示传感器坐标系（sensor/lidar frame）
- 下标 $t$ 表示时间步

**记忆技巧**：
- "w" = world（世界坐标系，固定不动）
- "s" = sensor（传感器坐标系，随机器人运动）

**示例**：
- $\mathbf{p}^w$ 表示点在世界坐标系下的坐标
- $\mathbf{p}^s_t$ 表示点在 $t$ 时刻传感器坐标系下的坐标

---

### 2.2 静态点云累积（公式 1）

静态地图通过体素网格（Voxel Grid）维护，每个体素存储点云统计信息（观测次数、最后观测时间）。

**公式 1：静态点云累积函数**
$
\begin{aligned}
\mathcal{A}(\mathcal{P}_t, t) = \Big\{ \mathbf{p}^w \in \mathcal{P}_t \mid & \mathcal{V}\left(\mathbf{i}(\mathbf{p}^w)\right).\text{count} \geq N_{\text{thresh}}(\mathbf{p}^w) \\
& \land \, t - \mathcal{V}\left(\mathbf{i}(\mathbf{p}^w)\right).\text{last}_{\text{seen}} \leq T_{\text{expire}} \Big\}
\end{aligned}
$

其中体素索引函数：
$
\mathbf{i}(\mathbf{p}^w) = \left[ \frac{\mathbf{p}^w - \mathbf{p}_{\text{origin}}}{s_{\text{voxel}}} \right]
$

**公式解释**：
- 将点云 $\mathcal{P}_t$ 中的每个点 $\mathbf{p}^w$ 映射到体素索引 $\mathbf{i}(\mathbf{p}^w)$
- 累积体素观测次数：$\mathcal{V}(\mathbf{i}).\text{count} \leftarrow \mathcal{V}(\mathbf{i}).\text{count} + 1$
- 更新观测时间：$\mathcal{V}(\mathbf{i}).\text{last\_seen} \leftarrow t$
- **静态判定**：观测次数 $\geq N_{\text{thresh}}(\mathbf{p}^w)$ 的体素被认为是静态点（使用自适应阈值）
- **老化机制**：超过 $T_{\text{expire}}$ 时间未观测到的点会被移除

**变量说明**：

| 变量 | 含义 | 单位 |
|------|------|------|
| $\mathcal{P}_t$ | $t$ 时刻的输入点云 | - |
| $\mathbf{p}^w$ | 点在世界坐标系下的坐标 | m |
| $\mathbf{p}_{\text{origin}}$ | 体素网格原点 | m |
| $s_{\text{voxel}}$ | 体素大小 | m |
| $\mathcal{V}(\mathbf{i})$ | 索引为 $\mathbf{i}$ 的体素 | - |
| $N_{\text{thresh}}(\mathbf{p}^w)$ | 自适应静态点判定阈值 | - |
| $T_{\text{expire}}$ | 过期时间阈值 | s |

**数值示例**：
- 体素大小：$s_{\text{voxel}} = 0.1$ m
- 静态阈值：$N_{\text{thresh}} = 3 \sim 5$（根据距离自适应调整）
- 过期时间：$T_{\text{expire}} = 5.0$ s（超过此时间未观测到的点会被移除）

### 2.3 空间自适应静态判别（公式 1.5）

考虑到激光雷达点云分布的距离非均匀性与稀疏性特征，本算法设计了空间自适应的静态判别模型。该模型构建了基于距离梯度的置信度自适应函数，在近场区域通过高置信度阈值抑制传感器高频噪声，在远场区域通过松弛约束以保障弱纹理区域的特征召回率，实现了全场感知的一致性。

**公式 1.5：距离自适应阈值函数**
$
N_{\text{thresh}}(\mathbf{p}^w) = \max\left(N_{\text{min}}, N_{\text{base}} - \left[ \frac{d(\mathbf{p}^w)}{d_{\text{step}}} \right]\right)
$

其中点到传感器的距离：
$
d(\mathbf{p}^w) = \sqrt{(p_x^w - p_{\text{sensor}}^x)^2 + (p_y^w - p_{\text{sensor}}^y)^2}
$

**公式解释**：
- 静态判定阈值 $N_{\text{thresh}}$ 不再是固定值，而是根据点到传感器的距离 $d(\mathbf{p}^w)$ 动态调整
- **近场高阈值**：距离 $< 5$ m 时，使用基准阈值 $N_{\text{base}}$（通常为 5），抑制传感器噪声
- **远场松弛约束**：距离每增加 $d_{\text{step}}$ m，阈值降低 1，补偿点云稀疏性
- **最小阈值保护**：阈值不低于 $N_{\text{min}}$（通常为 2），避免过度松弛导致误判

**分段阈值示例**（$N_{\text{base}} = 5$，$N_{\text{min}} = 2$，$d_{\text{step}} = 5$ m）：

| 距离范围 | 距离平方 $d^2$ | 阈值 $N_{\text{thresh}}$ | 物理意义 |
|---------|---------------|------------------------|---------|
| $d < 5$ m | $d^2 < 25$ | 5 | 近场：高阈值抑制噪声 |
| $5 \leq d < 10$ m | $25 \leq d^2 < 100$ | 4 | 中场：适度降低阈值 |
| $10 \leq d < 20$ m | $100 \leq d^2 < 400$ | 3 | 远场：进一步松弛 |
| $d \geq 20$ m | $d^2 \geq 400$ | 2 | 极远场：最小阈值保障召回率 |

**变量说明**：

| 变量 | 含义 | 典型值 | 单位 |
|------|------|--------|------|
| $N_{\text{thresh}}(\mathbf{p}^w)$ | 点 $\mathbf{p}^w$ 的自适应静态判定阈值 | 2-5 | - |
| $N_{\text{base}}$ | 基准阈值（近场） | 5 | - |
| $N_{\text{min}}$ | 最小阈值（远场保护） | 2 | - |
| $d(\mathbf{p}^w)$ | 点到传感器的水平距离 | - | m |
| $d_{\text{step}}$ | 距离分段步长 | 5 | m |
| $\mathbf{p}_{\text{sensor}}$ | 传感器在世界坐标系下的位置 | - | m |

**设计原理**：
1. **近场噪声抑制**：激光雷达在近距离（< 5m）点云密集但噪声较大，需要更多观测次数（5次）才能确认为静态点
2. **远场稀疏补偿**：远距离（> 20m）点云稀疏，降低阈值至 2 次观测即可判定，提高弱纹理区域的特征召回率
3. **平滑过渡**：中间距离采用线性递减策略，避免阈值突变导致的不连续性

**数值示例**：
- 近场点（3m）：需要观测 5 次才判定为静态
- 中场点（8m）：需要观测 4 次
- 远场点（15m）：需要观测 3 次
- 极远场点（25m）：需要观测 2 次

### 2.4 射线投射递减（公式 2）

射线投射用于清除保护区内的体素，防止动态物体累积到静态地图中。

**公式 2：射线投射递减函数**
$
\mathcal{R}(\mathcal{P}_t, \mathcal{B}) = \left\{ \mathbf{p}^w \in \mathcal{P}_t \cup \mathcal{M} \mid \mathbf{p}^w \in \mathcal{B}(\mathcal{D}_t) \land \mathbf{p}^w \notin \mathcal{H}_t \land \exists \mathbf{p}_e^w \in \mathcal{P}_t: \mathbf{p}^w \in \text{Ray}(\mathbf{p}_{\text{sensor}}^w, \mathbf{p}_e^w) \right\}
$

其中保护区域定义：
$
\mathcal{B}(\mathcal{D}_t) = \bigcup_{i=1}^{|\mathcal{D}_t|} \left\{ \mathbf{p}^w \mid \max_{k \in \{x,y,z\}} \left( \frac{|p_k^w - B_i^k|}{B_i^{w_k}/2} \right) \leq 1 \right\}
$

射线路径定义（Bresenham 3D，包含终点）：
$
\text{Ray}(\mathbf{p}_0, \mathbf{p}_1) = \left\{ \mathbf{p}^w \mid \mathbf{p}^w \text{ 在从 } \mathbf{p}_0 \text{ 到 } \mathbf{p}_1 \text{ 的体素遍历路径上} \right\}
$

递减规则：
$
\mathcal{V}(\mathbf{i}).\text{count} \leftarrow \max(0, \mathcal{V}(\mathbf{i}).\text{count} - \Delta_{\text{decr}}) \quad \forall \mathbf{p}^w \in \mathcal{R}(\mathcal{P}_t, \mathcal{B})
$

**公式解释**：
- 对于保护区内的所有体素（$\mathbf{p}^w \in \mathcal{B}$），如果满足以下任一条件则进行递减：
  - 该体素对应当前帧的激光点（$\mathbf{p}^w \in \mathcal{P}_t$）
  - 该体素在射线路径上且不是当前帧被观测到的（$\mathbf{p}^w \notin \mathcal{H}_t$ 且 $\mathbf{p}^w \in \text{Ray}(\cdot)$）
- 递减量 $\Delta_{\text{decr}}$ 通常设为 1，当 hit_count 降至 0 时从地图中移除

**变量说明**：

| 变量 | 含义 | 单位 |
|------|------|------|
| $\mathcal{P}_t$ | $t$ 时刻的输入点云 | - |
| $\mathcal{M}$ | 当前静态地图 | - |
| $\mathcal{B}(\mathcal{D}_t)$ | 动态保护区域 | - |
| $\mathcal{D}_t$ | $t$ 时刻的动态物体集合 | - |
| $\mathcal{H}_t$ | 当前帧被观测到的体素集合 | - |
| $\mathbf{p}^w$ | 体素对应的点（可能是激光点或路径点） | m |
| $\mathbf{p}_e^w$ | 激光点 | m |
| $\mathbf{p}_{\text{sensor}}^w$ | 传感器在世界坐标系下的位置 | m |
| $(B_i^x, B_i^y, B_i^z)$ | 第 $i$ 个边界框中心坐标 | m |
| $(B_i^{w_x}, B_i^{w_y}, B_i^{w_z})$ | 第 $i$ 个边界框尺寸 | m |
| $\Delta_{\text{decr}}$ | 递减量 | - |

**设计原理**：
1. **动态物体不应累积**：保护区内的体素（包括激光点和射线路径）会被递减，防止动态物体累积到静态地图
2. **选择性递减**：只对保护区内的体素递减，保护区外的稳定静态物体不受影响
3. **当前帧保护**：当前帧被观测到的体素不递减，避免误删除新发现的静态物体
4. **快速清除残影**：动态物体移动后，其原位置的体素通过递减快速清除

**数值示例**：
- 动态物体边界框：中心 $(2.0, 3.0, 1.0)$ m，尺寸 $(0.5, 0.5, 1.8)$ m
- 保护区域：$x \in [1.75, 2.25]$，$y \in [2.75, 3.25]$，$z \in [0.1, 1.9]$ m
- 传感器位置：$(0, 0, 0)$ m
- 激光点 $(2.0, 3.0, 1.0)$ m 在保护区内：该点对应的体素 hit_count 递减 1
- 激光点 $(5.0, 3.0, 1.0)$ m 在保护区外：该点对应的体素正常累积
- 射线路径上的体素如果在保护区内且不是当前帧观测到的，则 hit_count 递减 1

## 3. 代码实现

### 3.1 静态地图更新（关键代码）

```cpp
// 更新静态地图（对应总公式）
void StaticPointFilter::updateMap(
    pcl::PointCloud<pcl::PointXYZ>::Ptr cloud,
    double currentTime,
    const Eigen::Vector3d& sensorPos,
    const std::vector<box3D>* protectedBoxes) {
  
  // 清空当前帧命中集合
  current_frame_hits_.clear();

  // 【第一遍】处理终点体素（公式 1 + 公式 2）
  for (const auto& point : cloud->points) {
    // 检查点是否在保护区域内
    bool in_protected_area = false;
    if (protectedBoxes != nullptr) {
      for (const auto& box : *protectedBoxes) {
        if (isPointInBox(point, box)) {
          in_protected_area = true;
          break;
        }
      }
    }
    
    long long key = getVoxelKey(point);
    
    if (in_protected_area) {
      // 保护区内：递减（公式 2）
      auto it = voxel_map_.find(key);
      if (it != voxel_map_.end()) {
        if (it->second.hit_count <= ray_cast_decrement_) {
          voxel_map_.erase(it);
        } else {
          it->second.hit_count -= ray_cast_decrement_;
        }
      }
    } else {
      // 非保护区：累积（公式 1）
      current_frame_hits_.insert(key);
      VoxelStatus &status = voxel_map_[key]; 
      status.last_seen_time = currentTime;
      if (status.hit_count <= hit_threshold_ + 1) {
        status.hit_count++;
      }
    }
  }

  // 【第二遍】射线投射递减（公式 3）
  const int ray_cast_skip_interval = 5;
  ray_cast_skip_counter_ = 0;
  for (const auto &point : cloud->points) {
    ray_cast_skip_counter_++;
    if (ray_cast_skip_counter_ >= ray_cast_skip_interval) {
      rayCast(sensorPos, point, protectedBoxes);
      ray_cast_skip_counter_ = 0;
    }
  }

  // 每帧清理一次地图（老化机制）
  frame_count_++;
  if (frame_count_ >= 1) {
    cleanMap(currentTime);
    frame_count_ = 0;
  }
}
```

### 3.2 射线投射递减（Bresenham 3D）

```cpp
// 射线投射递减（对应公式 3）
void StaticPointFilter::rayCast(
    const Eigen::Vector3d &sensor_position,
    const pcl::PointXYZ &end_point,
    const std::vector<box3D> *protected_boxes) {
  
  // 将起点和终点转换为体素索引
  int x0 = std::floor(sensor_position.x() / voxel_size_);
  int y0 = std::floor(sensor_position.y() / voxel_size_);
  int z0 = std::floor(sensor_position.z() / voxel_size_);

  int x1 = std::floor(end_point.x / voxel_size_);
  int y1 = std::floor(end_point.y / voxel_size_);
  int z1 = std::floor(end_point.z / voxel_size_);

  // Bresenham 3D 算法遍历射线路径
  // ... (省略 Bresenham 步进逻辑)

  for (int i = 0; i < dm - 1; ++i) {
    // ... (Bresenham 步进)
    
    long long key = getVoxelKeyFromCoords(x, y, z);
    
    // 【规则1】当前帧被观测的体素：绝对不清除
    if (current_frame_hits_.count(key) > 0) {
      continue;
    }
    
    auto it = voxel_map_.find(key);
    if (it == voxel_map_.end()) {
      continue;
    }
    
    // 检查当前体素是否在保护区内
    bool in_protected = false;
    if (protected_boxes != nullptr) {
      pcl::PointXYZ voxel_center;
      voxel_center.x = x * voxel_size_ + voxel_size_ / 2.0f;
      voxel_center.y = y * voxel_size_ + voxel_size_ / 2.0f;
      voxel_center.z = z * voxel_size_ + voxel_size_ / 2.0f;
      
      for (const auto &box : *protected_boxes) {
        if (isPointInBox(voxel_center, box)) {
          in_protected = true;
          break;
        }
      }
    }
    
    if (in_protected) {
      // 【规则2】保护区内递减
      if (it->second.hit_count <= ray_cast_decrement_) {
        voxel_map_.erase(it);
      } else {
        it->second.hit_count -= ray_cast_decrement_;
      }
    }
  }
}
```

## 4. 边界情况处理

| 情况 | 处理方法 |
|------|----------|
| 传感器位置异常 | 检查 `sensorPos` 是否有效（`isfinite`），无效则跳过更新 |
| 点云为空 | 直接返回，不执行射线投射 |
| 动态物体边界框为空 | 正常执行累积，无保护区域（$\mathcal{B} = \emptyset$） |
| 体素网格过大 | 限制地图范围（如 50m × 50m），超出范围的点不加入 |
| 射线投射耗时过长 | 使用降采样（每5个点做一次射线投射） |
| 数值精度问题 | 使用整数体素索引避免浮点误差 |
