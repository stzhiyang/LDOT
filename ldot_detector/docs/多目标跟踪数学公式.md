# 多目标跟踪数学公式

## 1. 算法流程

多目标跟踪模块负责对点云进行聚类、检测、关联和状态估计，主要解决以下问题：
- **自适应聚类**：使用基于KD-Tree优化的自适应DBSCAN算法，根据距离动态调整搜索半径
- **异常过滤**：过滤尺寸异常的边界框，去除墙壁、建筑物等大型静态物体
- **鲁棒数据关联**：融合马氏距离和3D IoU的复合代价函数，使用匈牙利算法求解最优匹配
- **几何特征分类**：根据尺寸和质心特征分类为人、车、无人机或其他
- **自适应状态估计**：基于新息的自适应多模型卡尔曼滤波，在线调整过程噪声和观测噪声

**总公式**（多目标跟踪流程）：

$$
\text{Tracks}_{t} = \mathcal{T}_{\text{manage}} \left( \mathcal{T}_{\text{adaptive-filter}} \left( \mathcal{T}_{\text{classify}} \left( \mathcal{T}_{\text{assoc}} \left( \mathcal{T}_{\text{filter-box}} \left( \mathcal{T}_{\text{cluster}} \left( \mathcal{P}_t \right) \right), \text{Tracks}_{t-1} \right) \right) \right) \right)
$$

其中：
- $\mathcal{T}_{\text{cluster}}(\cdot)$：自适应DBSCAN聚类函数（公式1）
- $\mathcal{T}_{\text{filter-box}}(\cdot)$：异常边界框过滤函数（公式2）
- $\mathcal{T}_{\text{assoc}}(\cdot)$：鲁棒数据关联函数（公式3）
- $\mathcal{T}_{\text{classify}}(\cdot)$：几何特征分类函数（公式4）
- $\mathcal{T}_{\text{adaptive-filter}}(\cdot)$：自适应卡尔曼滤波函数（公式5-7）
- $\mathcal{T}_{\text{manage}}(\cdot)$：轨迹管理函数（处理新生、消失轨迹）

## 2. 核心公式

### 2.1 坐标系与符号定义

**坐标系**：
- **世界坐标系（Map Frame）**：$\{W\}$，所有跟踪计算在此坐标系下进行
- **状态向量**：$\mathbf{x}_t \in \mathbb{R}^n$，表示目标在时刻 $t$ 的状态（位置、速度、加速度等）

**符号约定**：
- **上标**：
  - $\mathbf{x}^{(i)}_t$：第 $i$ 个轨迹在时刻 $t$ 的状态
  - $D_i$：第 $i$ 个当前帧检测
  - $T_j$：第 $j$ 个历史轨迹
- **下标**：
  - $\mathbf{x}_{t|t-1}$：基于 $t-1$ 时刻信息对 $t$ 时刻的预测
  - $\mathbf{x}_{t|t}$：基于 $t$ 时刻测量的更新估计

**记忆技巧**：
- 上标 $(i)$ 表示"第几个对象"（轨迹或检测）
- 下标 $t|t-1$ 表示"预测"（用过去预测现在）
- 下标 $t|t$ 表示"更新"（用当前测量修正估计）

**示例**：
- $\mathbf{x}^{(3)}_{5|4} = \left[ x, y, z, v_x, v_y, v_z \right]^\top$：第3个轨迹在时刻5的预测状态（基于时刻4）

### 2.2 自适应聚类

**公式 1：基于KD-Tree优化的自适应DBSCAN**

$$
\begin{aligned}
\mathcal{C} &= \text{DBSCAN}(\mathcal{P}, \epsilon_{\text{adapt}}(p_i), N_{\min}) \\
\epsilon_{\text{adapt}}(p_i) &= \epsilon_{\text{base}} \cdot \left( 1 + \alpha \cdot \frac{d(p_i)}{d_{\text{ref}}} \right) \\
d(p_i) &= \|\mathbf{p}_i - \mathbf{p}_{\text{sensor}}\|
\end{aligned}
$$

**变量说明**：

| 变量 | 含义 | 单位/范围 |
|------|------|-----------|
| $\mathcal{P}$ | 输入点云集合 | - |
| $\mathcal{C}$ | 输出聚类集合 | - |
| $p_i$ | 第 $i$ 个点 | - |
| $\epsilon_{\text{adapt}}(p_i)$ | 点 $p_i$ 的自适应邻域搜索半径 | m |
| $\epsilon_{\text{base}}$ | 基础搜索半径 | m |
| $\alpha$ | 距离缩放系数 | 无量纲 |
| $d(p_i)$ | 点到传感器的欧氏距离 | m |
| $d_{\text{ref}}$ | 参考距离 | m |
| $N_{\min}$ | 最小点数阈值 | 整数 |

**设计思想**：
- 激光雷达点云密度随距离增加而显著降低
- 近处使用较小半径以分离密集物体
- 远处使用较大半径以避免稀疏点云过分割
- KD-Tree加速邻域搜索，提高计算效率

**数值示例**：
假设基础半径 $\epsilon_{\text{base}} = 0.3$ m，点距离 $d(p_i) = 20$ m，参考距离 $d_{\text{ref}} = 10$ m，缩放系数 $\alpha = 0.5$，则：

$$
\epsilon_{\text{adapt}}(p_i) = 0.3 \times \left( 1 + 0.5 \times \frac{20}{10} \right) = 0.3 \times 2.0 = 0.6 \text{ m}
$$

### 2.3 异常边界框过滤

**公式 2：尺寸过滤**

$$
\text{Valid}(\mathcal{B}) = \begin{cases}
\text{True}, & \text{if } w_x \leq w_x^{\max} \text{ and } w_y \leq w_y^{\max} \text{ and } w_z \leq w_z^{\max} \\
\text{False}, & \text{otherwise}
\end{cases}
$$

其中 $\mathcal{B} = \{x, y, z, w_x, w_y, w_z\}$ 为边界框（中心位置 + 尺寸）。

**变量说明**：

| 变量 | 含义 | 单位 |
|------|------|------|
| $w_x, w_y, w_z$ | 边界框在X、Y、Z轴的尺寸 | m |
| $w_x^{\max}, w_y^{\max}, w_z^{\max}$ | 最大允许尺寸 | m |

**设计思想**：过滤掉尺寸过大的聚类（如墙壁、建筑物），只保留合理尺寸的动态目标。

### 2.4 鲁棒数据关联

**公式 3：融合运动状态与几何形态的复合代价函数**

$$
\begin{aligned}
C_{ij} &= w_{\text{pos}} \cdot d_{MH}(D_i, T_j) + w_{\text{iou}} \cdot \left(1 - \text{IoU}_{3D}(D_i, T_j)\right) \\
d_{MH}(D_i, T_j) &= \sqrt{\left( \mathbf{z}_i - \mathbf{H} \mathbf{x}_{j|t-1} \right)^\top \mathbf{S}_j^{-1} \left( \mathbf{z}_i - \mathbf{H} \mathbf{x}_{j|t-1} \right)} \\
\mathbf{S}_j &= \mathbf{H} \mathbf{P}_{j|t-1} \mathbf{H}^\top + \mathbf{R} \\
\text{Assignment} &= \underset{\pi \in \Pi}{\arg\min} \sum_{i=1}^{M} C_{i, \pi(i)}, \quad \text{s.t. } C_{ij} < \gamma_{\text{gate}}
\end{aligned}
$$

**变量说明**：

| 变量 | 含义 | 单位/范围 |
|------|------|-----------|
| $D_i$ | 当前帧的第 $i$ 个观测 | - |
| $T_j$ | 第 $j$ 个历史轨迹 | - |
| $C_{ij}$ | 观测 $D_i$ 与轨迹 $T_j$ 的关联代价 | $[0, +\infty)$ |
| $d_{MH}$ | 马氏距离（Mahalanobis Distance） | 无量纲 |
| $\text{IoU}_{3D}$ | 三维交并比 | $[0, 1]$ |
| $w_{\text{pos}}, w_{\text{iou}}$ | 位置代价和IoU代价的权重 | 无量纲 |
| $\mathbf{S}_j$ | 新息协方差矩阵 | $\text{m}^2$ |
| $\gamma_{\text{gate}}$ | 卡方分布门控阈值 | 无量纲 |

**设计思想**：
- **马氏距离**：利用卡尔曼滤波的预测协方差归一化位置差异，自适应处理不同轴向的不确定性
- **3D IoU**：约束物体的体积重合度，提高几何一致性
- **匈牙利算法**：求解全局最小代价分配矩阵，实现观测与轨迹的最优匹配
- **卡方分布门控**：基于统计显著性拒绝不可靠匹配

**数值示例**：
假设观测与轨迹的马氏距离为 $d_{MH} = 2.5$，3D IoU为 $\text{IoU}_{3D} = 0.6$，权重 $w_{\text{pos}} = 1.0, w_{\text{iou}} = 0.5$，则：

$$
C_{ij} = 1.0 \times 2.5 + 0.5 \times (1 - 0.6) = 2.7
$$

如果门限 $\gamma_{\text{gate}} = 5.0$，则 $C_{ij} < 5.0$，该匹配有效。

### 2.5 几何特征分类与运动建模

**公式 4：基于几何特征的物体分类**

$$
\text{Class}(\mathcal{B}, \mathbf{c}) = \begin{cases}
\text{Human}, & \text{if } \frac{w_z}{\max(w_x, w_y)} > \tau_h^z \text{ and } c_z < w_z \cdot \tau_h^c \\
\text{Vehicle}, & \text{if } \frac{\max(w_x, w_y)}{w_z} > \tau_v^{xy} \text{ and } c_z < w_z \cdot \tau_v^c \\
\text{UAV}, & \text{if } w_x < \tau_u^s \text{ and } w_y < \tau_u^s \text{ and } w_z < \tau_u^s \text{ and } c_z > w_z \cdot \tau_u^c \\
\text{Other}, & \text{otherwise}
\end{cases}
$$

**变量说明**：

| 变量 | 含义 | 单位/范围 |
|------|------|-----------|
| $\mathcal{B} = \{w_x, w_y, w_z\}$ | 边界框尺寸 | m |
| $\mathbf{c} = \{c_x, c_y, c_z\}$ | 点云质心（相对于边界框底部） | m |
| $\tau_h^z$ | 人类高宽比阈值（$Z/XY$ 比例） | 无量纲 |
| $\tau_h^c$ | 人类质心高度比阈值 | 无量纲 |
| $\tau_v^{xy}$ | 车辆宽高比阈值 | 无量纲 |
| $\tau_v^c$ | 车辆质心高度比阈值 | 无量纲 |
| $\tau_u^s$ | 无人机最大尺寸阈值 | m |
| $\tau_u^c$ | 无人机质心高度比阈值 | 无量纲 |

**分类规则与运动模型**：

1. **行人（Human）**：
   - 几何特征：高瘦特征（较高的 $Z/XY$ 比例），质心靠下
   - 运动模型：**恒定加速度（CA）模型**
   - 状态向量：$\mathbf{x} = \left[ x, y, z, v_x, v_y, a_x, a_y \right]^\top \in \mathbb{R}^7$
   - 滤波器：标准线性卡尔曼滤波（KF）

2. **车辆（Vehicle）**：
   - 几何特征：扁平特征（较大的水平尺寸），质心高度较低
   - 运动模型：**恒定转弯率和加速度（CTRA）模型**
   - 状态向量：$\mathbf{x} = \left[ x, y, z, v, a, \psi, \dot{\psi} \right]^\top \in \mathbb{R}^7$
   - 滤波器：扩展卡尔曼滤波（EKF）

3. **无人机（UAV）**：
   - 几何特征：尺寸较小，处于悬浮状态（质心靠上）
   - 运动模型：**三维恒定加速度（CA）模型**
   - 状态向量：$\mathbf{x} = \left[ x, y, z, v_x, v_y, v_z, a_x, a_y, a_z \right]^\top \in \mathbb{R}^9$
   - 滤波器：标准线性卡尔曼滤波（KF）

4. **其他（Other）**：
   - 几何特征：不满足上述条件的物体
   - 运动模型：**恒定速度（CV）模型**
   - 状态向量：$\mathbf{x} = \left[ x, y, z, v_x, v_y, v_z \right]^\top \in \mathbb{R}^6$
   - 滤波器：标准线性卡尔曼滤波（KF）

**数值示例**：
假设边界框尺寸 $w_x = 0.5$ m，$w_y = 0.5$ m，$w_z = 1.7$ m，质心高度 $c_z = 0.6$ m，阈值 $\tau_h^z = 2.0$，$\tau_h^c = 0.5$，则：

$$
\begin{aligned}
\frac{w_z}{\max(w_x, w_y)} &= \frac{1.7}{0.5} = 3.4 > 2.0 \quad \checkmark \\
c_z &= 0.6 < 1.7 \times 0.5 = 0.85 \quad \checkmark
\end{aligned}
$$

分类结果：**Human**（行人），使用CA模型进行跟踪。

### 2.6 基于新息的自适应状态估计

**公式 5：新息序列与自适应噪声估计**

$$
\begin{aligned}
\boldsymbol{\nu}_k &= \mathbf{z}_k - \mathbf{H} \mathbf{x}_{k|k-1} \quad \text{（新息）} \\
\hat{\mathbf{C}}_{\nu} &= \frac{1}{W} \sum_{i=k-W+1}^{k} \boldsymbol{\nu}_i \boldsymbol{\nu}_i^\top \quad \text{（新息样本协方差）} \\
\hat{\mathbf{R}}_k &= \hat{\mathbf{C}}_{\nu} - \mathbf{H} \mathbf{P}_{k|k-1} \mathbf{H}^\top \quad \text{（自适应观测噪声）} \\
\hat{\mathbf{Q}}_k &= \mathbf{K}_k \left( \hat{\mathbf{C}}_{\nu} - \mathbf{H} \mathbf{P}_{k|k-1} \mathbf{H}^\top - \mathbf{R} \right) \mathbf{K}_k^\top \quad \text{（自适应过程噪声）}
\end{aligned}
$$

**变量说明**：

| 变量 | 含义 | 单位 |
|------|------|------|
| $\boldsymbol{\nu}_k$ | 时刻 $k$ 的新息（Innovation） | m |
| $\hat{\mathbf{C}}_{\nu}$ | 新息序列的样本协方差 | $\text{m}^2$ |
| $W$ | 滑动窗口大小 | 整数 |
| $\hat{\mathbf{R}}_k$ | 在线估计的观测噪声协方差 | $\text{m}^2$ |
| $\hat{\mathbf{Q}}_k$ | 在线估计的过程噪声协方差 | $\text{m}^2, (\text{m/s})^2$ |
| $\mathbf{K}_k$ | 卡尔曼增益 | - |

**设计思想**：
- 传统卡尔曼滤波使用固定的 $Q$ 和 $R$，难以应对突发的观测抖动
- 维护新息序列滑动窗口，实时计算样本协方差 $\hat{\mathbf{C}}_{\nu}$
- 基于 $\hat{\mathbf{C}}_{\nu}$ 在线估计当前的观测噪声 $\hat{\mathbf{R}}_k$ 和过程噪声 $\hat{\mathbf{Q}}_k$
- 当检测抖动增大时，自动增大 $R$，降低对当前量测的信任度
- 当物体进行机动时，调整 $Q$，增加对模型预测不确定性的容忍度

**噪声更新策略**：

$$
\begin{aligned}
\mathbf{R}_{k+1} &= (1 - \lambda) \mathbf{R}_k + \lambda \hat{\mathbf{R}}_k \\
\mathbf{Q}_{k+1} &= (1 - \lambda) \mathbf{Q}_k + \lambda \hat{\mathbf{Q}}_k
\end{aligned}
$$

其中 $\lambda \in (0, 1)$ 为平滑因子，用于避免噪声估计的剧烈波动。

### 2.7 多模型卡尔曼滤波框架

**公式 6：线性模型（CA, CV）的标准卡尔曼滤波**

**预测步骤**：

$$
\begin{aligned}
\mathbf{x}_{k|k-1} &= \mathbf{F} \mathbf{x}_{k-1|k-1} \\
\mathbf{P}_{k|k-1} &= \mathbf{F} \mathbf{P}_{k-1|k-1} \mathbf{F}^\top + \hat{\mathbf{Q}}_k
\end{aligned}
$$

**更新步骤**：

$$
\begin{aligned}
\mathbf{K}_k &= \mathbf{P}_{k|k-1} \mathbf{H}^\top \left( \mathbf{H} \mathbf{P}_{k|k-1} \mathbf{H}^\top + \hat{\mathbf{R}}_k \right)^{-1} \\
\mathbf{x}_{k|k} &= \mathbf{x}_{k|k-1} + \mathbf{K}_k \boldsymbol{\nu}_k \\
\mathbf{P}_{k|k} &= (\mathbf{I} - \mathbf{K}_k \mathbf{H}) \mathbf{P}_{k|k-1}
\end{aligned}
$$

其中 $\mathbf{H} = \left[ \mathbf{I}_{3 \times 3} \mid \mathbf{0}_{3 \times (n-3)} \right]$ 为测量矩阵（提取位置）。

---

**公式 7：非线性模型（CTRA）的扩展卡尔曼滤波**

**预测步骤**：

$$
\begin{aligned}
\mathbf{x}_{k|k-1} &= \mathbf{f}(\mathbf{x}_{k-1|k-1}, \Delta t) \\
\mathbf{F}_k &= \frac{\partial \mathbf{f}}{\partial \mathbf{x}} \bigg|_{\mathbf{x}_{k-1|k-1}} \quad \text{（雅可比矩阵）} \\
\mathbf{P}_{k|k-1} &= \mathbf{F}_k \mathbf{P}_{k-1|k-1} \mathbf{F}_k^\top + \hat{\mathbf{Q}}_k
\end{aligned}
$$

**更新步骤**：与线性模型相同（公式6）。

**CTRA模型的非线性状态转移函数**：

$$
\mathbf{f}(\mathbf{x}, \Delta t) = \begin{bmatrix}
x + \frac{v}{\dot{\psi}} \left( \sin(\psi + \dot{\psi} \Delta t) - \sin(\psi) \right) \\
y + \frac{v}{\dot{\psi}} \left( -\cos(\psi + \dot{\psi} \Delta t) + \cos(\psi) \right) \\
z \\
v + a \Delta t \\
a \\
\psi + \dot{\psi} \Delta t \\
\dot{\psi}
\end{bmatrix}
$$

**退化情况**（$\dot{\psi} \approx 0$，直线运动）：

$$
\mathbf{f}(\mathbf{x}, \Delta t) \approx \begin{bmatrix}
x + v \Delta t \cos(\psi) + \frac{1}{2} a \Delta t^2 \cos(\psi) \\
y + v \Delta t \sin(\psi) + \frac{1}{2} a \Delta t^2 \sin(\psi) \\
z \\
v + a \Delta t \\
a \\
\psi \\
0
\end{bmatrix}
$$

### 3.2 鲁棒数据关联

```cpp
void dynamicDetector::boxAssociation(std::vector<int> &bestMatch) {
  // 构建代价矩阵
  for (int i = 0; i < numCurrObjs; ++i) {
    for (int j = 0; j < numHistObjs; ++j) {
      // 计算马氏距离
      Eigen::Vector3d posDiff = measPos - predPos;
      Eigen::Matrix3d S_inv = S.inverse();
      double d_MH = std::sqrt(posDiff.transpose() * S_inv * posDiff);
      
      // 计算3D IoU
      double iou_3d = compute3DIoU(measBox, predBox);
      
      // 复合代价函数
      double cost = w_pos * d_MH + w_iou * (1.0 - iou_3d);
      
      // 卡方分布门控
      if (cost < gamma_gate) {
        costMatrix[i][j] = cost;
      }
    }
  }
  
  // 匈牙利算法求解最优匹配
  hungarianAlgorithm(costMatrix, bestMatch);
}
```

### 3.3 自适应噪声估计

```cpp
// 基于新息的自适应噪声估计
void KalmanFilter::adaptiveNoiseEstimation() {
  // 计算新息
  Eigen::VectorXd innovation = measurement - H * x_pred;
  
  // 更新新息历史窗口
  innovationHistory.push_back(innovation);
  if (innovationHistory.size() > windowSize) {
    innovationHistory.pop_front();
  }
  
  // 计算新息样本协方差
  Eigen::MatrixXd C_nu = Eigen::MatrixXd::Zero(3, 3);
  for (const auto& nu : innovationHistory) {
    C_nu += nu * nu.transpose();
  }
  C_nu /= innovationHistory.size();
  
  // 估计观测噪声
  Eigen::MatrixXd R_hat = C_nu - H * P_pred * H.transpose();
  
  // 估计过程噪声
  Eigen::MatrixXd Q_hat = K * (C_nu - H * P_pred * H.transpose() - R) * K.transpose();
  
  // 平滑更新
  R = (1.0 - lambda) * R + lambda * R_hat;
  Q = (1.0 - lambda) * Q + lambda * Q_hat;
}
```

## 4. 边界情况处理

| 情况 | 处理方法 |
|------|----------|
| **新目标出现** | 初始化新轨迹，使用CV模型，速度初始化为0 |
| **目标消失** | 使用预测状态维持轨迹（Coasting），超过 `maxMissedFrames_` 后删除 |
| **遮挡导致尺寸突变** | 使用历史最大尺寸，启动尺寸变化计数器，连续确认后接受新尺寸 |
| **协方差矩阵奇异** | 添加正则化项 $\mathbf{P} + \epsilon \mathbf{I}$（$\epsilon = 10^{-2}$） |
| **CTRA模型角速度为0** | 退化为直线运动模型（见公式7退化情况） |
| **匈牙利算法无匹配** | 标记为新目标，初始化新轨迹 |
| **静态物体Coasting** | 强制速度和加速度为0，重置卡尔曼滤波器状态 |
| **观测抖动增大** | 自适应增大 $R$，降低对当前量测的信任度 |
| **物体机动** | 自适应增大 $Q$，增加对模型预测不确定性的容忍度 |

## 附录：参数配置建议

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| `epsilon_base` | 0.3 m | 基础邻域搜索半径 |
| `alpha` | 0.5 | 距离缩放系数 |
| `d_ref` | 10.0 m | 参考距离 |
| `N_min` | 5 | DBSCAN最小点数阈值 |
| `w_pos` | 1.0 | 位置代价权重 |
| `w_iou` | 0.5 | IoU代价权重 |
| `gamma_gate` | 5.0 | 卡方分布门控阈值 |
| `maxMissedFrames_` | 5 | 最大丢失帧数 |
| `windowSize` | 10 | 新息滑动窗口大小 |
| `lambda` | 0.1 | 噪声平滑因子 |

**调参建议**：
- **密集场景**：减小 `epsilon_base`（如0.2m），提高聚类分辨率
- **稀疏场景**：增大 `alpha`（如0.8），增强远距离自适应能力
- **高动态场景**：增大 `lambda`（如0.2），加快噪声自适应速度
- **低动态场景**：减小 `lambda`（如0.05），提高噪声估计稳定性
