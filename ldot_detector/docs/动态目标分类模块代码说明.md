# 动态目标分类数学公式

## 1. 算法流程

动态目标分类模块负责判断跟踪的目标是否为动态物体。该模块通过分析点云的运动一致性和时间连续性，实现鲁棒的动静态物体判别。

算法主要分为三个步骤：

1. **速度估计**：从卡尔曼滤波器获取物体速度估计
2. **点云运动一致性检查**：通过逐点速度计算和投票机制判断物体运动状态
3. **动态一致性检查**：通过时间连续性过滤偶然误判

**总公式**（引用子模块）：

$$
\text{IsDynamic}(i, t) = \mathcal{F}_{\text{force}}(i, t) \lor \left[\mathcal{F}_{\text{motion}}(i, t) \land \mathcal{F}_{\text{consist}}(i, t)\right]
$$

其中：
- $\mathcal{F}_{\text{force}}$ 对应公式 1（强制动态判定）
- $\mathcal{F}_{\text{motion}}$ 对应公式 2（点云运动一致性）
- $\mathcal{F}_{\text{consist}}$ 对应公式 3（动态一致性检查）

## 模块架构

根据系统框架图，动态目标分类模块包含两个核心子模块：

```
动态目标分类 (Object Dynamic Classification)
```

## 核心算法流程

### 1. 点云运动一致性检查（Point Cloud Motion Consistency）

#### 1.1 算法原理

点云运动一致性检查通过比较当前帧和历史帧的点云数据，计算每个点的运动速度，并与边界框整体速度进行对比，从而判断物体是否在运动。

#### 1.2 关键步骤

**步骤1：获取卡尔曼滤波器估计的速度**

```cpp
// 从卡尔曼滤波器获取速度估计
Eigen::Vector3d Vkf(0., 0., 0.);
Eigen::VectorXd state = this->filters_[i]->getState();
int dim = state.size();

if (dim == 6) {
  // 3D CV模型: [x, y, z, vx, vy, vz]
  Vkf(0) = state(3);
  Vkf(1) = state(4);
  Vkf(2) = state(5);
} else if (dim == 7) {
  // 7维模型（Human CA 或 Vehicle CTRA）
  bool isVehicle = this->boxHist_[i][0].is_che;
  if (isVehicle) {
    // CTRA: [x, y, z, v, a, yaw, yaw_rate]
    double v = state(3);
    double yaw = state(5);
    Vkf(0) = v * cos(yaw);
    Vkf(1) = v * sin(yaw);
  } else {
    // Human CA: [x, y, z, vx, vy, ax, ay]
    Vkf(0) = state(3);
    Vkf(1) = state(4);
  }
} else if (dim == 9) {
  // 3D CA模型 (UAV): [x, y, z, vx, vy, vz, ax, ay, az]
  Vkf(0) = state(3);
  Vkf(1) = state(4);
  Vkf(2) = state(5);
}

double velNorm = Vkf.norm();
```

**步骤2：强制动态判定（历史动态频率检查）**

```cpp
// 如果物体在过去一段时间内频繁被判定为动态，则强制认定为动态
int dynaFrames = 0;
if (int(this->boxHist_[i].size()) > this->forceDynaCheckRange_) {
  for (int j = 1; j < this->forceDynaCheckRange_ + 1; ++j) {
    if (this->boxHist_[i][j].is_dynamic) {
      ++dynaFrames;
    }
  }
}

// 双重条件：历史动态帧数 + 当前速度阈值
if (dynaFrames >= this->forceDynaFrames_ && velNorm >= this->dynaVelThresh_ * 0.8) {
  this->boxHist_[i][0].is_dynamic = true;
  dynamicBBoxesTemp.push_back(this->boxHist_[i][0]);
  continue;
}
```

**步骤3：计算边界框中心速度**

```cpp
// 计算边界框中心点的速度（基于位置差分）
Eigen::Vector3d Vbox(0., 0., 0.);
int curFrameGap = 1;  // 当前帧与历史帧的间隔

Vbox(0) = (this->boxHist_[i][0].x - this->boxHist_[i][curFrameGap].x) / 
          (this->dt_ * curFrameGap);
Vbox(1) = (this->boxHist_[i][0].y - this->boxHist_[i][curFrameGap].y) / 
          (this->dt_ * curFrameGap);
Vbox(2) = (this->boxHist_[i][0].z - this->boxHist_[i][curFrameGap].z) / 
          (this->dt_ * curFrameGap);
```

**步骤4：逐点速度计算与投票**

```cpp
int numPoints = currPc.size();  // 点云总点数
int votes = 0;                  // 动态投票数

// 遍历当前点云中的每一个点
for (size_t j = 0; j < currPc.size(); ++j) {
  double minDist = this->classificationMinNeighborDist_;
  Eigen::Vector3d nearestVect;
  
  // 在历史点云中寻找最近邻点
  for (size_t k = 0; k < prevPc.size(); k++) {
    double dist = (currPc[j] - prevPc[k]).norm();
    if (abs(dist) < minDist) {
      minDist = dist;
      nearestVect = currPc[j] - prevPc[k];
    }
  }
  
  // 计算该点的速度
  Eigen::Vector3d Vcur = nearestVect / (this->dt_ * curFrameGap);
  
  // 对于人物/车辆，忽略Z轴速度（平面运动）
  // 对于无人机/其他类别，保留Z轴速度（3D运动）
  if (!(this->boxHist_[i][0].is_uav || this->boxHist_[i][0].is_else)) {
    Vcur(2) = 0;
  }
  
  // 计算速度方向相似度（余弦相似度）
  double velSim = Vcur.dot(Vbox) / (Vcur.norm() * Vbox.norm());
  
  // 如果速度方向相反，认为是噪声或匹配错误，不计入总点数
  if (velSim < 0) {
    --numPoints;
  } else {
    // 如果点的速度超过动态阈值，投一票"动态"
    if (Vcur.norm() > this->dynaVelThresh_) {
      ++votes;
    }
  }
}
```

**步骤5：计算动态投票率**

```cpp
// 计算动态票的比例
double voteRatio = (numPoints > 0) ? double(votes) / double(numPoints) : 0;
```

**步骤6：基于尺寸的自适应判定**

```cpp
// 获取物体当前尺寸
double x_width = this->boxHist_[i][0].x_width;
double y_width = this->boxHist_[i][0].y_width;
double z_width = this->boxHist_[i][0].z_width;
double max_size = std::max({x_width, y_width, z_width});

// 判断是否为小型物体
bool is_small_object = (max_size < this->classifyUAVMaxSize_);

bool is_dynamic_candidate = false;

// 小型物体使用宽松条件
if (is_small_object || this->boxHist_[i][0].is_uav) {
  if (velNorm >= this->dynaVelThresh_ * 2) {
    // 速度非常高，直接判定为动态
    this->boxHist_[i][0].is_dynamic = true;
  } else if (velNorm >= this->dynaVelThresh_ * 1.5) {
    // 小型物体：主要依赖卡尔曼滤波器速度，投票率要求降低
    is_dynamic_candidate = (voteRatio >= 0.3);
  }
} else {
  // 正常判定逻辑（大型物体）
  is_dynamic_candidate = (voteRatio >= this->dynaVoteThresh_ && 
                          velNorm >= this->dynaVelThresh_);
}
```

### 2. 动态一致性检查（Dynamic Consistency）

#### 2.1 算法原理

动态一致性检查通过检查物体在连续多帧中是否持续被判定为动态候选，从而过滤掉偶然的误判，提高动态分类的鲁棒性。

#### 2.2 关键步骤

**步骤1：标记动态候选**

```cpp
if (is_dynamic_candidate) {
  this->boxHist_[i][0].is_dynamic_candidate = true;
  
  // 进行动态一致性检查
  int dynaConsistCount = 0;
  if (int(this->boxHist_[i].size()) >= this->dynamicConsistThresh_) {
    for (int j = 0; j < this->dynamicConsistThresh_; ++j) {
      if (this->boxHist_[i][j].is_dynamic_candidate ||
          this->boxHist_[i][j].is_dynamic) {
        ++dynaConsistCount;
      }
    }
  }
  
  // 只有连续多帧都是动态候选，才最终判定为动态
  if (dynaConsistCount == this->dynamicConsistThresh_) {
    this->boxHist_[i][0].is_dynamic = true;
    dynamicBBoxesTemp.push_back(this->boxHist_[i][0]);
  }
}
```

**步骤2：更新最终动态障碍物列表**

```cpp
// 直接更新最终的动态障碍物列表
this->dynamicBBoxes_ = dynamicBBoxesTemp;
```

## 关键参数说明

### 点云运动一致性参数

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `dynaVelThresh_` | double | 0.5 m/s | 判定为动态的速度阈值 |
| `dynaVoteThresh_` | double | 0.5 | 判定为动态的投票比例阈值 |
| `classificationMinNeighborDist_` | double | 0.5 m | 点云匹配的最大距离 |
| `classifyUAVMaxSize_` | double | 1.0 m | 小型物体（无人机）的尺寸阈值 |

### 动态一致性参数

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `dynamicConsistThresh_` | int | 3 帧 | 动态一致性检查的帧数阈值 |
| `forceDynaFrames_` | int | 5 帧 | 强制判定为动态的历史帧数阈值 |
| `forceDynaCheckRange_` | int | 10 帧 | 检查强制动态的历史范围 |

## 算法特点

### 1. 多层次判定机制

- **第一层：强制动态判定** - 基于历史动态频率，避免已确认的动态物体被误判为静态
- **第二层：点云运动一致性** - 基于点级速度投票，精细判断物体运动状态
- **第三层：动态一致性检查** - 基于时间连续性，过滤偶然误判

### 2. 自适应阈值策略

- **小型物体**（尺寸 < 1.0m）：降低投票率要求（0.3），提高速度阈值（1.5倍）
- **大型物体**：使用标准阈值（投票率 0.5，速度 0.5 m/s）
- **无人机类别**：保留Z轴速度，支持3D运动判定

### 3. 速度方向一致性检查

通过计算点速度与边界框速度的余弦相似度，过滤掉方向相反的噪声点，提高判定准确性。

### 4. 分类感知的运动模型

- **人物/车辆**：忽略Z轴速度，专注于平面运动
- **无人机/其他**：保留Z轴速度，支持3D运动判定

## 常见问题与解决方案

### 问题1：低速物体被误判为静态

**原因**: 速度阈值过高，或投票率要求过严格

**解决方案**:
- 降低 `dynaVelThresh_` 参数（如从 0.5 降至 0.3）
- 降低 `dynaVoteThresh_` 参数（如从 0.5 降至 0.4）
- 启用强制动态判定机制

### 问题2：静态物体被误判为动态

**原因**: 点云噪声导致误匹配，或动态一致性阈值过低

**解决方案**:
- 增加 `dynamicConsistThresh_` 参数（如从 3 增至 5）
- 增加 `classificationMinNeighborDist_` 参数，提高匹配精度
- 启用速度方向一致性检查

### 问题3：小型物体（无人机）检测不稳定

**原因**: 点云稀疏，投票率不稳定

**解决方案**:
- 已实现自适应阈值策略（投票率降至 0.3）
- 增加对卡尔曼滤波器速度的依赖权重
- 考虑使用更长的历史窗口

动态目标分类模块通过点云运动一致性检查和动态一致性检查两个子模块，实现了鲁棒的动静态物体判别。该模块的核心优势在于：
